本轮修了什么（v5.7）

问题说明修法
大蒜换行跨了水陆
"陆路僵尸吃大蒜不会去水路，水路僵尸吃大蒜也不会去陆路"		 上一版抄了"相邻两路随机二选一"的通用说法，把 2 路写成 → 1 或 3 路、 5 路写成 → 4 或 6 路。3/4 路是水池，陆路僵尸根本下不去 —— 所以实际只有唯一去向，不存在"分流"。
这也解释了为什么 2-9 / 5-9 的大蒜是单向驱赶：
2-9 → 只能去 1 路　5-9 → 只能去 6 路		 换行表改成 {1:2, 2:1, 3:4, 4:3, 5:6, 6:5}， 并在 _garlic() 里按地形再过滤一遍（表写错也翻不了车）。
实测（10 局）：来源 2路 257 / 5路 143，去向 1路 257 / 6路 143 —— 一条都没跑错。
连带效应：岸路压力不再被水路的忧郁菇分担，全部灌进边路， 南瓜修补 2 → 27 次/局，波长 9.16 → 9.40s（+10%），但 CORE 仍零损失、等级仍 L3。
极速关选卡写错了 之前给极速关列了 `I′`（复制冰）却没有咖啡豆 —— PE 是白天场地，冰菇种下去不点咖啡豆根本不会生效。 而且极速关本来就不带复制冰。 极速选卡改为：冰 / 大蒜 / 樱桃 / 辣椒 / 南瓜 / 南瓜′ / 咖啡豆 / 荷叶 / 大喷 / 曾哥（无 I′，有咖啡豆）。
极速关不该带核 极速关的出怪里没有冰车、没有投篮车（实测 20 波：铁门 272、撑杆 146、 潜水 136、海豚 109、跳跳 85、小丑 79、舞王 79、读报 62 …… 冰车 0、投篮 0）。 核弹本来是用来炸车和巨人的，没有目标就纯属浪费一个卡位。 把 N 换成大蒜，种在 2-9 / 5-9 并持续维护。 大蒜 400 血、一口 100（啃 4 口碎），靠换行把岸路僵尸单向赶去边路 （2 路→1 路、5 路→6 路，不跨水陆）。实测 95 次换行 / 23 次啃碎。 报告新增大蒜台账（换行次数 / 啃碎次数 / 来源 / 去向）。
问题根因 / 说明修法
开局阳光不是社区的 8k 社区运阵表演视频约定俗成：每个 2F 开局 8000 阳光。 设计意图是两头兼顾 —— 既不轻易摸到 9990 上限（真打到就说明经济特别好）， 又给了极大的亏损空间（运阵不被阳光限制，同时还能看出经济状况）。 之前模拟按 1000 跑，等于把"经济压力"放大了 8 倍。 默认 `SUN0 = 8000`，并把阳光封顶 9990（`SUN_CAP`）。 报告里 KPI 直接写"阳光结余（8000 起）"，旁边挂峰值； 一旦某局真的触顶会标红 `⚠触顶`。
阵线参差不齐 之前只输出"这一波有僵尸的路"，3/4 路（水路）常常整行消失。 固定输出 1~6 路，没僵尸写"无"（水路降权）。 海豚 / 矿工 / 小鬼 这类已脱离阵线的僵尸不计入 —— 见下。
问题根因修法
刷怪时序
"所有的怪都是同一时刻内刷出来的，刷怪地点的微小差异在简化模型中忽略"		 之前按 SPAWN_GAP 6~16cs 逐只错开生成。这个加工有两个副作用： ① 人为拉长波长；② 造出"第二辆冰车晚出生"这种不存在的两难。 所有僵尸 due = 刷新时刻，出生点固定第 10 列。 于是"同路冰车视觉重合"自动成立 —— 一个窝瓜压死整条路是机制结果， 不需要额外假设。w11 落 5-9 不再有两难。
窝瓜的判定形态
"视作一个 1 格宽的、1.8k 伤害即刻生效的攻击判定域"		 之前是"种下 → 等 6s 出怪结束 → 选中一只 → 扣血"， 等于给窝瓜编了一套不属于它的时延和索敌逻辑。 重写成 _ash_cell()：判定域 [cx−40, cx+40]， 与受击框相交即生效，对本行所有相交僵尸各 1800，无时延。 这同时解释了"为什么窝瓜能 100% 保住 5-9"： 车头进 [640,720] 就爆，而车尾（冰道前沿，+80）还在 720~800，9 列还没被铺。
变速"冰不够"
"变速关最后存冰结余这么多，你说冰不够我不信"		 用户质疑得对。冰一直是够的，账能平（慢速 121 供 / 97 消 / 剩 24； 变速 114 / 92 / 剩 22）。真正的原因是三条叠加： ① _kernel_slack 要求"必须和下个固定核复用同一个坑"， 变速波长下永远为负 → 整局只点 2 次核； ② AA' 被写成"点核后的下一波"，于是每 4 波只肯用 1 次灰烬， 其余全退化成冰；③ w19 救急把最后一个冰点掉，w20 冰杀蹦极没冰。 ① _kernel_slack 改成按坑位数判定（9 个坑、2-9/5-9 只留给锚点）， 核从 2 → 4 次；② AA' 独立化（不再依附核），樱桃辣椒 50s CD 各 4 次都用上； ③ 救急层在 w19/w20 保住最后一个冰。结果：空窗 0，存冰 3.8。
波长口径 刷怪改成同刻后，四档波长整体偏快 19~24%（极速只差 6%）。 极速是"纯 IO、不操作"，它准 → IO 模型准；其余档偏快 → 灰烬+冰的等效清血被高估约 1.25 倍。 不篡改机制，把偏差记成显式标定系数 R2_CALIB = 0.80 （R2_THRESHOLD = wiki 0.50~0.65 × 0.80）。 调完四档 −2% / −3% / −8% / +4%。 将来若把灰烬对数修准，把系数调回 1.0 即可。
1/6 路"不致死"的理由写错了 之前写"CORE 在 3 列，7~8 列炸不到"。结论对，过程错。 改为：边路小丑在 6 列就被双大喷打死 / 早爆炸空 （1-4/1-5、6-4/6-5 的火力线）。真正受小丑威胁的 CORE 是 岸路 6 列眼曾（2-6 / 5-6），而边路小丑走不到能威胁它的位置。
极速关的"不操作"被当成缺陷 空窗统计把极速关 16 个常规波全标红，但那是策略不是漏操作。 控丑台账改三态：严谨 / 有限（列出空窗波号）/ 策略性放弃。

分级口径（脱离设计怎么判）

等级含义典型现象怎么处理
L0 致命不可接受控丑空窗 / 冰慢一拍 / 蹦极无冰 / CORE 被毁，且人类也挤不出资源来阻止后果不可逆（CORE 死 / 后场被偷光），没有任何补救
L1 人类手感内可避免练手感就能补同样是致命事件，但造成它的原因人类能设法阻止（只差一个冰 / 卡差两秒 / 换个顺序就能挤出来）属"手滑"不属"设计错"：练临场补一手即可
L2 能补付阳光就能补不在设计内的损失（非 CORE 植物死 / 被碾），但阵有冗余、阳光能补回合理运阵下不该发生；发生了就付阳光
L3 正常磨损本来就正常必然发生、且设计已预留补偿（南瓜磨损 —— 选卡带南瓜就是为补它）不用管，算进日常开销
L4 模型伪影模型的问题波长偏差 ≥ 10% 引起的现象不是打法问题，需重新标定
判定原则：先问"玩家能不能靠看场面补一手" —— 能，就是 L1（不是设计错）； 再问"补的代价是不是只有阳光" —— 是，就是 L2； 再看"这是不是本来就这么打" —— 是，就是 L3。L4 只归因于模型，不归因于打法。
