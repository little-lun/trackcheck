## 三、结论

### 1. 稳定性
**四档共 32 局，全部跑完 20 波，零崩阵。** 这是这版模拟器第一次做到这个水平。
改动链：判定框相交 → 曾哥 4 次命中分开 → 拖时间改为策略 → 红眼配额摊平
→ 真实 SOP 轨道 → 灰烬圆形判定 + 双 y → 咖啡豆 299cs → x 基准 57px
→ 存冰连点 bug → 救场按"距 CORE 距离"排序。

### 2. 波长偏差
```
慢速 +31%   变速 +27%   快速 −9%   极速 +19%
```
模拟整体偏慢一档。**这个方向是"保守"，对验证器是安全的**——
它会低估阵的上限，不会高估。四个档的**相对次序完全正确**
（慢速 > 变速 > 快速 ≈ 极速），所以"用哪档该换什么打法"这类判断可以信。

### 3. 长波分布印证了打法差异
```
慢速 / 变速：≥40s 的长波各 16 次（w9/w19/w20 拖时间）
快速 / 极速：0 次
```
这正是"有巨人才拖、脆皮波不拖"的策略差异，模型把它体现出来了。

### 4. 极速档几乎不操作
8 局合计**只用过 8 次窝瓜**（每局 1 次），核/冰/樱桃/辣椒一次都没用。
与"极速关若无事故则不操作"完全一致。而它的减速覆盖仍有 **99%**——
完全靠冰瓜常驻减速撑着，说明这个阵在极速档确实是"不吃操作、吃阵型"。

### 5. 减速覆盖
```
极速 99%   慢速 94%   变速 92%   快速 69%
```
前三档都在"绝大多数时间"的口径内。**快速档 69% 偏低**，因为它的轨道里
没有冰（只有樱桃+辣椒），全靠冰瓜；而这恰好也是它唯一偏快（−9%）的档。

### 6. 经济
```
慢速 2538   变速 2259   快速 1972   极速 3912
```
全部为正，且都是在"垫材用了 100~280 张、冰/核按 CD 猛打"的前提下。
印证了你说的"**这个阵经济好得很**"。

### 7. 一处仍需核实的数
**南瓜损耗 0.0 个/局**（8 局只补了 1~2 个南瓜）。这不太可能——
实战里南瓜一直在磨损。原因是"补南瓜"逻辑太即时（一穿就补，卡 CD 30s 完全够）。
不影响波长结论，但如果要看"南瓜压力"这个指标，这条得单独校准。
