# trackcheck v0.3 发布说明

> PVZ 初代（1.0.0.1051 EN）生存无尽研究工具：
> **布阵 → 选怪 → 编阵解 → 跑运阵 → 出报告**。
>
> 这一版有两个形态，内容完全一样（同一套引擎），挑一个发就行。
>
> **本版新增：英文界面（0.3.1 起为全覆盖）。** 右上角齿轮 →「设置 · 语言 / Language」可切到 English；
> 切换后整页重载。英文界面下 PVZ 原版内容用官方英文名（小丑 = Jack-in-the-Box Zombie），
> 本来就是字母的社区术语（P/A/A′/I/N、io、DE/NE/PE/FE/RE、C4io/P4…）保持原样，
> 解释见「帮助 → 语言说明 / Language notes」。

> **已装过旧版的人不必卸载** —— 直接双击新的 `trackcheck-v0.3-setup.exe`，
> 它会把安装目录默认指到原来那一个，选「是」就是原地升级（见第三节末尾）。

## 一、发哪个文件？

| 文件 | 大小 | 适合谁 | 需要联网 |
|---|---|---|---|
| `trackcheck-v0.3.html` | 16.3 MB | **想省事的人**：一个文件，双击就开，断网也能算 | 不需要 |
| `trackcheck-v0.3-web.html` | 0.99 MB | 网速好、只是发个链接/小文件 | 首次打开需要 |
| `trackcheck-v0.3-setup.exe` | 23.4 MB | **想要"装个软件"的人**：开始菜单、卸载条目齐全 | 不需要 |

三个都在 `tools/trackcheck/dist/`。发的时候**单个文件直接发就行**，
不用压缩（HTML 可以直接当附件、当网盘文件、当邮件附件）。

> ★ **内部版本只出 html + exe**（2026-10-24 用户定的轻量化规则）：
> 没有 release 的版本**不生成** `setup.exe`；只有正式发布时才
> `python -m tools.trackcheck.build_win --release`，
> 那一步会先把同一发布内所有 `0.x.n` 的更新日志**合并**成 `更新日志-v0.3.md`，再打安装包。

## 二、网页版：不用服务器，也不用装任何东西

### 怎么给别人

1. 把 `trackcheck-v0.3.html` 发过去（微信 / QQ / 网盘 / 邮件都行）；
2. 对方**双击**它 —— 会用默认浏览器打开；
3. 看到「正在启动运阵引擎…」等 3~5 秒，页面出来就能用。

就这样。**没有服务器、没有账号、没有安装、不上传任何东西**，
所有计算都在对方浏览器里完成。

> 想放在网上给人下载？直接把这个 .html 传到 GitHub Releases / 网盘，
> 或者扔进任意静态托管（GitHub Pages、Cloudflare Pages）。
> 它本身就是完整的网页，不需要任何后端。

### 两个版本的区别

- **`trackcheck-v0.3.html`（离线版）**：CPython 的 WebAssembly 运行时
  （Pyodide）＋我们的引擎全在这个文件里，约 16MB。断网、内网、飞行模式都能跑。
- **`trackcheck-v0.3-web.html`（在线版）**：文件只有 0.99MB，首次打开时
  从 CDN 下 12MB 引擎（unpkg → jsdelivr 依次重试），之后浏览器会缓存。
  **内网/墙内环境请优先发离线版**，免得 CDN 连不上。

### 要求

- 浏览器：新版 **Edge / Chrome / Firefox**（要支持 WebAssembly 和
  `blob:` 模块导入）。IE、很久没更新的旧浏览器不行。
- 内存：约需 300MB 空闲（引擎本身占 150MB 左右）。
- 从 `file://` 打开完全没问题 —— 页面不会向任何服务器发请求（离线版一个请求都没有）。

### 报告怎么"存下来"

- 每组报告右上角「⤓ 下载 PDF」：**网页版**会弹出浏览器的打印对话框，
  目标选「另存为 PDF」即可（页面已经排好 A4 横向）。
- **桌面版**是真 PDF，直接下载文件。
- 出怪列表可以用「⤓ 导出 JSON」存下来，下次「⤒ 导入 JSON」直接恢复。

## 三、Windows 11 版：安装程序 / 主程序 / 卸载程序

### 三个程序分别是什么

```
trackcheck-v0.3-setup.exe    安装程序 —— 发给别人的就是这个
    └─ 里面装着 ↓ 两个
       TrackCheck.exe        主程序 —— 装完在开始菜单里点它
       Uninstall.exe         卸载程序 —— 装完自动放进安装目录
```

- **安装程序**（`trackcheck-v0.3-setup.exe`）
  双击 → 先问**装到哪**：
  「是」装到默认目录 `C:\Users\<你>\AppData\Local\Programs\TrackCheck\`；
  「否」弹出 Windows 原生的「浏览文件夹」让你自己选（选 `D:\Tools` 就装到
  `D:\Tools\TrackCheck`，选的就是 `…\TrackCheck` 则原样用；弹出的确认框里会写清
  最终路径）→ 复制两个 exe → 建开始菜单快捷方式（桌面快捷方式可选）→
  在「设置 → 应用」里登记一条卸载信息。
  **不需要管理员权限，也不往 `Program Files` 写任何东西。**
  装到哪个目录都能卸干净 —— 卸载程序以**自己所在目录**为准，不认死默认路径。
- **主程序**（`TrackCheck.exe`）
  双击 → 后台起一个只监听 `127.0.0.1:8765` 的小服务 → 用默认浏览器打开界面。
  界面上多一个「⏻ 退出程序」（网页版没有）；关掉浏览器页面后
  **30 分钟没有心跳会自动退出**，不会在后台偷偷挂着。
  编辑好的阵解可以「保存」到 `%APPDATA%\TrackCheck\plans\`（网页版不能写盘，
  请用「导出 JSON」）。
- **卸载程序**（`Uninstall.exe`）
  开始菜单「TrackCheck」右键卸载，或「设置 → 应用 → TrackCheck v0.3 → 卸载」。
  会清掉：安装目录、两个快捷方式、「应用和功能」里的条目。
  **研究资料与源码在工作目录里，卸载不会碰它们。**

### 首次运行会被 SmartScreen 拦一下

exe 没有代码签名，Windows 会提示「Windows 已保护你的电脑」：

> 点 **更多信息** → **仍要运行**。

这不是安装包坏了，是"没花钱买签名证书"的正常表现。介意的话就发网页版。

### 静默安装 / 静默卸载（给脚本和自测用）

```bat
trackcheck-v0.3-setup.exe /S                          :: 装到默认目录，不弹任何框
trackcheck-v0.3-setup.exe /S /D=D:\Tools\TrackCheck   :: 装到指定目录
"%LOCALAPPDATA%\Programs\TrackCheck\Uninstall.exe" /S :: 静默卸载
```

`/D=` 给的是**程序目录本身**（不会再自动追加 `TrackCheck`）。

### 从 v0.1 升级：直接覆盖，不用卸载

双击 `trackcheck-v0.3-setup.exe` → 它会先读注册表看有没有装过：

- 装过 → 默认目录**就是原来那个目录**，提示「检测到已安装旧版 → 覆盖升级到 v0.3」，选「是」开始
- 没装过 → 按新装走

升级时会做这几件事：

1. 如果 `TrackCheck.exe` 正开着，先把它关掉（会提示一下）
2. 覆盖两个 exe、重建开始菜单 / 桌面快捷方式、「应用和功能」里的版本号改成 v0.3
3. **`%APPDATA%\TrackCheck\plans\` 里的阵解一个都不会动** —— 升级只换程序，不碰存档

唯一会丢东西的情况：你自己把 v0.1 装在了 `D:\Tools\TrackCheck`，
升级时却在弹出的「浏览文件夹」里选了别处。**看到路径不对就点「否」重选**，
确认框里会写清最终装到哪。

## 四、它算什么、不算什么

- **算**：给定一份出怪列表，判断该用哪一档阵解、能不能跑通、
  常规波长多少、存冰/阳光/补南瓜够不够、哪里最险。
- **不算**：不是游戏本体，不读游戏内存，不连游戏进程；也没有"上机打一局"的功能。
- 引擎是**模型**：巨人 6000 血打满才算清除、曾哥 AoE 用**判定框相交**而不是中心点、
  冰道残留、大蒜被车碾、南瓜一格判定…… 这些口径都写在
  `tools/trackcheck/README.md` 里，出结论前建议看一眼对应版本小节。
- 版本前提：**原版 1.0.0.1051 EN**。RE 版（年度版）数值有出入，结论不能直接搬。
- **哪些东西真的建模了？** 点右上角**齿轮 → 建模清单**，里面逐条列了
  植物 18 种、僵尸 24 种、场地 5 个，每一行都标了保真级别和"哪里没做"：

  | 徽章 | 意思 |
  |---|---|
  | 完整 | 行为按原作参数模拟（伤害、CD、判定框都对得上） |
  | 部分 | 只做了"对本阵有影响"的那一部分（例：磁力菇只吸金属护具，不模拟"吸过来当子弹"） |
  | 只看风险 | 不影响数值，只在报告里出一条风险提示（例：蹦极） |
  | 只有数据 | 有血量/速度表，但没进模拟（例：雪人） |
  | 只作动作 | 种下去就是一次判定（例：核、樱桃、辣椒、窝瓜、三叶草、墓碑吞噬者） |

  **一句话现状**：**五个场地都能跑**（PE/FE/DE/NE/RE），形状与场地规则
  （水路、昼夜、浓雾、墓碑、斜坡、睡莲/花盆基座、禁出僵尸）都已建模；
  但只有 **PE** 有一套经过录像标定的阵型（电波钟无炮），其余四个场地
  要你自己摆阵再跑 —— 直接拿 PE 的阵型去跑 5 行场地会因为第 6 行植物不存在、
  以及陆地格上的曾哥被冰车碾而崩，这是**阵型不匹配**，不是程序错了。

## 五、出问题怎么查

| 现象 | 原因 / 处理 |
|---|---|
| 网页版一直停在「正在启动运阵引擎…」 | 在线版连不上 CDN → 改用离线版 `trackcheck-v0.3.html` |
| 网页版提示「引擎启动失败」 | 浏览器太旧（不支持 WebAssembly），换 Edge/Chrome 新版 |
| 双击 exe 没反应 | 可能已经有一个实例在跑：它会把浏览器指向 `http://127.0.0.1:8765/` |
| 端口 8765 被别的程序占了 | 换个端口：`TrackCheck.exe --port 8800` |
| 桌面版「下载 PDF」没反应 | 本机没有 Edge/Chrome 时无法无头打印 → 会退回打印页，用「另存为 PDF」 |
| 卸载后目录还在 | 极少数情况下文件被占用，重跑一次卸载或手动删掉该文件夹 |
| 装到了别的目录，卸载在哪找 | 就在那个目录里：`<你选的目录>\Uninstall.exe`，或「设置 → 应用」 |
| 升级后界面还是旧样子 | 浏览器缓存了旧页面 → `Ctrl+F5` 强制刷新；或确认「设置 → 应用」里版本已是 v0.3 |

`0.x.0` 表示那一版的打包基线。你能拿到的安装包文件名永远只到 `0.x`。

    南瓜存活的分母用实际阵型
  - **小丑**：早爆/晚爆权重按「这一路最靠前植物在第几列」取；控丑等级改成按结果判
  - **蹦极**：伞覆盖的植物与炮不会被偷；冰杀定式覆盖的必须让冰生效；炮阵可炮炸蹦极

  - **简写 / 复写**进设置（对称操作写一个还是一对）：自动辨认 / 简写 / 复写
  - 新增**波长串**输入框（<code>(9,9,9,9)</code> 或 <code>(9|9|9|9)</code>）与**波长和校验**：
    含 P 的循环 ≥ 36s（34~35s 极限警告）、含长 CD 卡 ≥ 54s，
    并推算"这个循环至少要几门炮"（N6s 的 54s → 4 门）
