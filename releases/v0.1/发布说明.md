# trackcheck v0.1 发布说明（2026-10-20）

首个对外分发版。

## 发哪个文件

| 文件 | 适合谁 | 需要联网 |
|---|---|---|
| `trackcheck-v0.1.html` | 一个文件，双击就开，断网也能算 | 不需要 |
| `trackcheck-v0.1-web.html` | 只想发个小文件 | 首次打开需要 |
| `trackcheck-v0.1-setup.exe` | 想装成软件（开始菜单 + 卸载条目） | 不需要 |

## 这一版有什么

- **自由勾选出怪** → 自动判定节奏档（慢速 / 变速 / 中速 / 快速 / 极速）
- 四套内置阵解（对应四档出怪）+ 极速关大蒜 / 结构位大喷分叉
- **报告**：KPI、分级、逐波时间轴、轨道执行表，以及存冰 / 冰车 / 大蒜 / 结构位大喷台账
- 出怪列表 JSON 导入导出、报告导出 PDF
- 两种分发形态：单文件 HTML（离线 / 在线）、Windows 安装包（安装 / 主程序 / 卸载三个程序）
- 安装程序支持**修改安装目录**

## 已知局限

- 阵型是内置的 PE.电波钟无炮，不能换场地、不能自编阵解
- 植物 / 僵尸只覆盖了 PE 常用的一批
