> PVZ 初代（1.0.0.1051 EN）生存无尽研究工具：**布阵 → 选怪 → 编阵解 → 跑运阵 → 出报告**。
> 这一版是 **0.2.7**（对外版本 `0.2` 的第七次改动）。装过旧版直接双击新的 setup 覆盖安装即可。

## 这一版改了什么

### 1. 轨道里能做的操作只剩两种
- **P（玉米炮）** 和 **种植物（卡片）**。
- 「窝瓜压车」这种特技操作**取消** —— 它就是"在 5-9 种窝瓜" + 一个「5 路冰车距 5-9 还剩 N px」的距离触发器。旧阵解导入时自动迁移。

### 2. P 操作重做
- **不需要指定具体哪一门炮**：每门炮各自有 3475cs 的装填计时器，引擎自动挑"装填好了、剩余 CD 最短"的那门。
- **忽略释放→爆炸时延**（写下的那一刻就爆）。
- 落点**行列都允许一位小数**（如 `3-4.5`）。
- 判定域 R=115，与僵尸**受击框**有重合就吃满 **1800**（所以一门炮覆盖 3 行）。

### 3. 轨道格式
认得四个结构符，快捷填充时按语义**留空**给你填：

| 符 | 名称 | 快捷布置怎么处置 |
|---|---|---|
| `|` | 隔离符（换波） | 下一拍 |
| `-` | 刷新符（同一波的第二个时机） | 同波再排一组，触发器 = 上一块之后，**时间留空** |
| `/` | 分场符（上下半场同时） | 进同一时机，落点全部留空 |
| `~` | 波动符（两套节奏摆动） | 两套**逐循环交替** |

「简写 / 复写」（对称操作写一个还是一对）放进设置，还能**自动辨认**：出现 `PP` 就当复写。

### 4. 波长串 + 校验
轨道右边新增「波长串」输入框，写 `(9,9,9,9)` 或 `(9|9|9|9)`：

- 含 P：波长和 ≥ 36s（34~35s 是极限，会警告；< 34s 判不可能）
- 含长 CD 卡（灰烬 / 冰）：≥ 54s，否则警告
- 自动推算「这个循环至少要几门炮」：`ceil(发数 ÷ (波长和 ÷ 34.75s))`
  - 例 `I-PP|I-PP|N|PP(18,18,9,9)` → 54s ≈ 1.55 个炮 CD，6 发 P → **4 门炮**够
