# trackcheck v1.0 · 第一个正式版

> PVZ 初代（1.0.0.1051 EN）生存无尽研究工具：**布阵 → 选怪 → 编阵解 → 跑运阵 → 出报告**。
> 内部版本 `1.0.0`。装过旧版（v0.1 / v0.2 / 0.3）直接双击新的 setup 覆盖安装即可。

## 这一版有什么

### 1. 桌面版是**真正的本地 app**
- 双击 `TrackCheck.exe` 直接开**原生窗口**（Edge WebView2 内核）——不再是"起个本地服务再跳浏览器"，
  没有地址栏 / 标签页 / 书签栏。
- 本地设置**落到磁盘**（`%LOCALAPPDATA%\TrackCheck\`）：语言、阵型草稿、出怪列表、简写设置关掉再开还在。
- 「设置 · 本地文件」可整包**导出 / 导入配置**，换台机器接着用。
- 「⤓ 下载 PDF」在桌面版直接弹 Windows「另存为」。
- 万一本机缺 WebView2 → 弹提示并**自动退回浏览器模式**，不至于打不开。

### 2. 英文界面全覆盖
- 右上角齿轮 →「设置 · 语言 / Language」一键切 English。
- PVZ 原版内容用**官方英文名**（小丑 = Jack-in-the-Box Zombie、曾哥 = Gloom-shroom、冰车 = Zomboni），
  社区字母术语（P/S/B/D/d/p、I、N、A、io、PE/FE/DE/NE/RE、C4io/P6-2i…）保持原样。

### 3. 阵解编辑器
- **炮积木 / 卡积木分离**：`P` 主炮、`S` 同步炮、`B` 提前炮、`D` 延迟（拦截）炮、`d` 尾炸炮、`p` 铲种炮；
  卡积木 = 植物卡（`c` 垫材、`C` 地刺、`a` 窝瓜…）。
- 冰变奏复合符号 `PI1 / PI2 / PI3 / cI4`（带「ICE3 只有 1cs 有效时机」「ICE4 至今无可应用阵」的提示）。
- **快捷布置 / 自动填充阵解**：给「阵容 + 轨道 + 波长串」就铺出全部阵解细节，直接开跑出报告。
  起手 = 刷怪后半个波长；其它波锚定上一波**最后一个**运算量。
- **分离炮动态落点 / 拦截动态落点 / 尾炸落点**；波长串单位自动识别（s / cs）。

### 4. 模拟模型（这一版最核心的准确性工作）
- **刷怪时间改成确定性规则**：开始后 6s 刷 w1；常规波 = 刷怪后等 4s → 27s 内血量掉到 **65%**
  （或窗口到期）→ 再等 2s 刷下一波；长间隔 = 45s（或全灭）+ 红字 7.2s；结束 = 49s（或全灭）+ 白字 5s。
  **没有随机血线 / 硬顶 / 标定系数**，同一个种子跑两遍完全一致。
- **受击判定域统一**：x 宽度按僵尸类型；y 轴统一为**一整格**且与格子上下界重合；
  `y行x列` 格 = `[y-1,y]×[x-1,x]`，格心 = 炮落点。
- **白天场的蘑菇**只有一种说法：「阵图里装着睡着的某种蘑菇的格子」——
  卡好了就「种下 + 同时点咖啡豆」，卡没好就点场上睡着的那个；那格被用掉变空后**持续判定用卡片（含模仿）补回去**。
- 投篮车：不啃植物、受冰冻减速（只有冰车免控）、索敌本路最靠左那株。
- 灰烬（P/N/A/A′）能杀**地下挖掘中的矿工**；`C`（地刺）令本行本波冰车全灭；
  P 的滑动落点覆盖全场但**不炸梯子**；窝瓜 = 1 格宽即刻 1800。
- 极限阵（不计阳光）模式；选卡自动生成；白天场蘑菇卡 CD 回退到模仿卡。

### 5. 报告
- 逐波时间轴 SVG、轨道执行表、控制手段台账（冰 / 灰烬 / 策略性放弃）、小丑 / 投篮 / 蹦极 / 核坑 / 南瓜收支、
  归因（谁在哪一格杀了什么）、等级判定 L0~L3。
- 「⤓ 下载 PDF」：桌面版原生另存为，网页版走浏览器打印。
