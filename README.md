# trackcheck · PVZ 初代生存无尽研究工具

> 用代码替代"上机打 2F"：**布阵 → 选怪 → 编阵解 → 跑运阵 → 出报告**。
> 引擎按 PvZ 1.0.0.1051 EN 的实测数值建模，可以离线跑在浏览器里，也可以装成 Windows 桌面程序。

## 一句话

把一条轨道（阵型 + 节奏 + 操作）丢进去，它告诉你**这条轨道能不能成立、会断在哪一波**。

```bash
python -m tools.trackcheck.run                       # 命令行跑一组
python -m tools.trackcheck.app                       # 起本地服务，浏览器里用
```

## 下载 / 使用

三个产物**内容完全一样**（同一套引擎），挑一个即可。大文件不进 git 树，请到
**Releases** 页面（`../../releases/latest`）下载。

| 文件 | 大小 | 适合谁 | 需要联网 |
|---|---|---|---|
| `trackcheck-v0.2.html` | 16 MB | **最省事**：一个文件，双击就开，断网也能算 | 不需要 |
| `trackcheck-v0.2-web.html` | 0.7 MB | 网速好、只想发个小文件 | 首次打开需要 |
| `trackcheck-v0.2-setup.exe` | 23 MB | **想装成软件**：开始菜单、卸载条目齐全 | 不需要 |

- 网页版：**没有服务器、没有账号、不上传任何东西**，所有计算都在你自己的浏览器里完成。
- 桌面版支持**原地覆盖升级**（装过旧版不用先卸载）。
- 详见 [releases/v0.2/发布说明.md](releases/v0.2/发布说明.md)。

## 它做什么

| 界面 | 干什么 |
|---|---|
| ① **阵容布置** | 选场地（PE/FE/DE/NE/RE）→ 画 5~6 × 9 的格子图 → 摆植物、套南瓜、搭梯、放底座；支持 **PvZ Tools / PvZ Toolkit 阵型字符串**导入导出 |
| ② **出怪沙盘** | 勾选这一关允许出现的僵尸，按场地自动锁定禁出种类（如 RE 不出舞王/矿工） |
| ③ **阵解编辑** | 节奏（双命名方案）+ 每波候选兜底链 + 积木/触发器 + 全场判定 + 简化救场；可配多套阵解并与出怪组匹配 |
| ④ **运行与报告** | 波长、偏差、减速覆盖、存冰/阳光/补南瓜台账、逐波时间轴、轨道执行表，可导出 PDF |

**它算什么**：判断轨道可行性的沙盘、找断裂点的工具、学习轨道理论的练手场。
**它不算什么**：不是游戏本体，不是外挂，不保证每个 cs 级窗口都精确
（模型保真度见工具里齿轮 → 模型清单）。

## 版本基准（研究数值的前提）

| 版本 | 位置 | 用途 | 本库适配 |
|---|---|---|---|
| **PvZ 1.0.0.1051 EN** | 本地安装目录（含 PvZ Tools 2.3.4） | **研究主力** | 全部数值以此为准 |
| **PvZ: Replanted** | EA app（Unity 重制，1.5.1） | 实战 / 对比 | **阵型通用、数值不通用** |

**三条硬规矩**：① 未声明版本时按 1.0.0.1051 EN 讨论；② 涉及 RE 版必须显式标注，
不得直接套用本库的 cs 级数值与内存地址；③ 跨版本推断标 `待核`。
