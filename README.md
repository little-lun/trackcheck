# PVZ 初代 · 生存无尽 研究与练习库

本工作区用于 **植物大战僵尸 · Survival Endless（生存无尽）** 的研究、学习与练习。
内容来自植吧（百度贴吧植物大战僵尸吧）体系与中文 PVZ Wiki，属于"轨道理论"范式下的知识整理。

**分层读法**：
- `01~07` = **玩法层**（怎么打赢）。先读这些。

- `11~12` = **工程层**（把研究变成可复现实验）。想量化验证时读。
- `13` = **边界条件**（哪些结论在哪失效）。**改动任何数值前先看它。**

**两份读本的分工**：旧版《轨道理论完全读本》是**体系**——讲轨道语言怎么来的、运算量、精度、变奏、超多炮、时空兑换；

## 三、学习路径（建议顺序）

### 阶段 0 · 环境（半天）
1. 装 PC 1.0 原版，打通冒险模式（**先别用修改器**，读本明确建议：通关约 10 小时）。
2. 用 Toolkit 解锁隐藏场地。
3. 装网页布阵器书签，练习画阵。

### 阶段 1 · 会说人话（1 周）
读 `01-基础` → `02-核心-刷新` → 新读本第 1 篇。
产出：能用"x 路 y 列"描述任意植物位置；能背出"6s / 45s / 7.2s / 49s / 5s"这套刷新时序。

### 阶段 2 · 第一个阵（2 周）
新读本第 1 篇实战 + `07-专题-阵型库` 的【传统八炮】。
目标：**冲过 100f**，能稳定做到 9 秒一对炮、落点 8 列偏左、舞王指天即发炮。

### 阶段 3 · 节奏与卡片（3~4 周）
`03-核心-轨道语言` → `04-核心-节奏体系` → 新读本第 2、3 篇。
目标：改打**经典十炮（P5, 7.2s）**与**经典十二炮（P6, 6s）**，掌握冰消珊瑚、梯子南瓜、冰杀小偷。

### 阶段 4 · 变奏（长期）
`04` 后半 + 新读本第 4、5 篇 + `06-专题-控丑`。
目标：能自己给一个阵**选节奏**——算冰平衡、查波长表、验复用。
这一步开始，你才是真的在"研究"而不是"抄阵"。

### 阶段 5 · 理论（选做，但推荐）
`08-节奏体系` → `09-出怪机制` → `10-无炮研究`。
目标：
- 能把任一阵型**归类**到六大节奏之一，并说出参数怎么算
- 能解释"为什么 47f 之前的数据不能当满强度"
- 能看懂"IO 4334"是什么意思，并判断一个无炮构型能不能扛

### 阶段 6 · 工程（选做）
`11-栈位理论` → `12-内存基址`。
目标：
- 装 AvZ，跑通一个最小脚本（选卡 → 发炮 → 退出）
- 读 `5594/5598` 验证一次真实刷新阈值
- 用 `158` 字段查一次栈位，解释一个"玄学"漏炸

## 四、四条必须记住的铁律

1. **2 个运算量 = 刷一波僵尸。** 这是全部轨道计算的根。炮 = 1，核 = 2，冰 = 0，垫材 = 0。
2. **波长决定生死。** 6s 是硬下限，7.46s 是加速波防投篮的上限，19.29s 是冰波防投篮的上限，
   11.5s / 20.3s 分别防早爆丑 / 晚爆丑。数值错 0.1s，阵就崩。
3. **先算后打。** 读本第 5 篇的原话：从"实践出真知"到"先论证后实践"。高精度阵型里 0.01s 都要算。
4. **"概率"都是幌子。** 海豚"概率跳过"其实是栈位 100%/0%；小丑"有时炸有时不炸"是波长没算对；
   出怪"看脸"背后是 MT19937 + 权重 + 级别。**看到概率，就说明还有没找到的确定变量。**
