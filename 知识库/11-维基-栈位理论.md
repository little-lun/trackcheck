## 一、栈位是什么

**栈位 = 编号 = 序号。** pvz 里并没有真正的栈，只有"类似栈"的结构。

类比：栈是一个深洞，往里依次放物品，**先进后出**，游戏只能访问**栈顶**。

### 1.1 植物序号的分配

初始化游戏时同时初始化一个栈，**初始只有元素 `0`**。

```
种下第一株植物：
  栈顶元素（0）出栈 → 成为该植物的序号
  → 判断栈是否为空 → 空 → 出栈的元素 +1（=1）→ 再入栈
```

植物消失后（**被铲除、被碾压并过了一段时间、灰烬爆炸、被丑炸**），其序号**入栈成为栈顶**，
将分配给**下一次种植**。

**例子**：
```
场上 a,b,c,d 序号 0,1,2,3，栈 [4]
铲掉 c → a,b,d 序号 0,1,3，栈 [2,4]（2 在顶）
种下 e → a,b,d,e 序号 0,1,3,2，栈 [4]
```

僵尸由**另一个栈**记录，死亡时序号回归栈顶。

> **低栈位 = 序号小**，反之亦然。

### 1.2 序列号（mRank / mNextKey）

仅在**蹦极**和**舞王**相关现象中用到，了解它不是必需的。

- 游戏内有初值 0 的计数器，植物/僵尸/子弹各一个
- 生成时赋予计数器当前值 = 序列号，然后计数器自增 1
- **重进关卡时计数器重置** → 可能导致蹦极抓取、舞王区分伴舞出错

> 蹦极/舞王判定 = **栈位 + 序列号**，两者都匹配才误判。

## 二、植物侧现象

### 2.1 海豚越过高坚果（最著名的栈位现象）

**前提**：只发生在"下水即跳跃"的海豚（即 8 列有植物）。

**静态（全程无操作）成立条件**：
```
① 8 列有高坚果（是否带套不影响）
② 7 列有空南瓜 / 高坚果 / 高坚果套南瓜
③ 7 列那个东西的栈位 低于 8 列高坚果
```

| 满足情况 | 结果 |
|---|---|
| ① + ②(空南瓜) + ③ | 跳过 8 列，落在 **7 列更左** |
| ① + ②(高坚果) + ③ | 跳过 8 列，但被 **7 列高坚果阻挡**，落在 7 列**较右** |
| 其他 | 被 8 列高坚果**阻拦** |

> ⚠️ **不存在"概率跳过"。满足条件就是 100%，不满足就是 0%。**
> 所谓"概率"只是人为操作让前后植物序号时大时小造成的错觉。
>
> ⚠️ 顺带纠正一个流传说法："**经典十炮高坚果带套会被海豚跳**"是**谣传**。

**动态（跳跃过程中有人操作）**：
对 n 列（1≤n≤7）高坚果，只要在一小段时间内于 **n+1 列**种一株
**栈位低于该高坚果的非高坚果植物**，海豚就会越过高坚果。

时间窗：
- 上界：**不晚于跳跃后 123cs**（124 触发碰撞判定）
- 下界：约**海豚半个头处在 n+1 与 n+2 列交界时**
- 早于下界：海豚落水后仍会不断啃高坚果，只是不会因被拦而落在高坚果前面

反向操作：跳跃后、跃后 124 前，在 n+1 列迅速种**荷叶 + 低栈高坚果**，
海豚会被拦在 n+1 列高坚果前（**对 n 列普通植物无法复现**）。

### 2.2 对植物的判定顺序

**若僵尸能同时攻击到两格的植物（巨人锤击、其余僵尸啃食），优先攻击序号较小的那个。**

格内有花盆/南瓜时顺序会稍复杂。

**两个实战推论**：
1. 炮阵中，可用**序号比炮小的垫材**来降低砸率。
2. 后置炮场景中，若 3 列南瓜/梯子南瓜栈位**比炮低**：
   小鬼在 **230px 时不啃炮，231px 时啃**；否则 **229px 不啃，230px 啃**。
   —— 1px 的差别，决定小鬼啃不啃你的炮。

### 2.3 蹦极与"栈位偷"

蹦极靠**栈位 + 序列号**确定要偷的植物。若能让目标植物拥有与蹦极所选植物**相同的栈位和序列号**，
目标植物就会被偷 —— 此即**栈位偷**。

**复现步骤**：
```
1. 在蹦极产生标靶到手开始收拢之间，退出重进一次，
   在蹦极所在格种下任意植物；之后到蹦极手完全收拢前，再挑一时刻退出重进一次
2. 在蹦极手开始收拢到完全收拢（摸到植物）间，铲除蹦极所在格植物，
   并于目标位置种下计划被偷的植物
3. 此时计划被偷植物在所种格子仍存在，同时蹦极所在格也有该植物的贴图
4. 蹦极手完全收拢后，计划被偷植物从所种格子消失，贴图随蹦极上升
```

**原理**：
- 步骤 1：第一次退出重进使该格第一株植物序列号为 0；第二次为种下一株 0 序列号植物作准备
- 步骤 2：蹦极锁定该格植物的序号与序列号（0）；铲除 → 序号回栈顶 →
  新种植物继承该栈位 + 序列号 0 → 被误认
- 步骤 3：手完全收拢前目标植物仍可交互（若是荷叶/花盆，要在此阶段种好负载植物）

**能玩出的花样**：
- 蹦极偷炮、**炮后轮悬空**（实例：水母十四炮）
- 植物下方无花盆荷叶而悬空
- **陆地荷叶 / 陆地猫**（BLS，Bungee Lilypad Skip / 飞贼荷叶 skip）
- 陆地或水上**无限叠种荷叶**、给海蘑菇和缠绕海草套南瓜、浮空南瓜套、荷叶与花盆/地刺/土豆雷叠种

**制造陆地猫还需要三个附加条件**（不全是栈位）：
1. 蹦极靠**自身所在格**决定偷猫后补种荷叶的格子（不是猫原来那格）
2. 补荷叶不涉及额外合法性判断
3. 种猫不判断需要水

### 2.4 Ice3 为什么"玄学"

用咖啡豆、模仿者等**具有交接生效倒计时**的植物时，存在切换计算问题，总时长会产生 **1cs** 变化。

对 ICE3 而言，**咖啡豆与寒冰菇的序号相对大小**会引起总生效倒计时的差异
—— 这就是 ICE3 容易失效的根因。

> 键控中的解法：改变生效时间的函数、或直接读内存。
> 这条与 `03` 里"咖啡豆 199/198 差 1cs"是同一件事。

## 三、僵尸侧现象

### 3.1 水草、大嘴花
攻击时**优先选择栈位较低**的僵尸。

### 3.2 空降僵尸（蹦极投下的三人组）

僵尸啃食判定是"出生后时间每为 4 的倍数造成一次 4hp 伤害"，蹦极下落 **375~394cs**。

若空降僵尸恰好落在植物上：
| 情况 | 结果 |
|---|---|
| 着地时间是 4 的倍数，且空降僵尸栈位 **低于** 蹦极 | 过 4cs 才造成伤害 |
| 着地时间是 4 的倍数，且栈位 **高于** 蹦极 | 落地时**立即**造成伤害 |
| 着地时间**不是** 4 的倍数 | 栈位无关，统一到下一个 4 的倍数才伤害 |

### 3.3 垫材（为什么要小心"车底垫"）

**多个僵尸同时对一个植物做碾压/跳跃/举锤判定时，从栈位最小的僵尸开始判定。**

两个典型现象：
1. **NE 九列种植物被立即碾压**：植物同时在篮球车与巨人的攻击域内。
   刚放置的 1cs 内，栈位低于所有篮球车的巨人先举锤，其后篮球车碾压，
   最后栈位高于篮球车的巨人才判定 —— 但植物已被碾压，**没垫到**，这些巨人继续走。
2. **屋顶车底垫花盆**：一部分撑杆尝试越过花盆，一部分继续行走。原理同上。

> ⚠️ **结论：僵尸栈位在正常游戏中不可控，所以"车底垫"消除砸率的操作不严谨、不被接受。**
> 例外：可以用**地刺、窝瓜、三叶草**车底垫全部巨人 —— 它们免疫碾压，且地刺种后 **26cs** 才扎车。

### 3.4 撑杆与土豆雷（能造"无敌土豆雷"）

土豆地雷遍历**本行**僵尸序号，**每一个无杆撑杆会使本行土豆雷的触发判定右移 40px（0.5 格）**；
而**已出土的土豆地雷是霸体状态**（免疫啃食，但车碾/巨人敲/小丑炸/子弹/辣椒僵尸/篮球仍能伤害）。

推论：
- **最少两个低栈位无杆撑杆 → 一个无敌土豆雷**
- 撑杆足够多、使触发判定右移到僵尸出生点右侧 → **土豆雷完全免疫本行僵尸啃食**
- 应用：伪和平 22 炮
- 也可反向用：多个撑杆把判定引到足够右，使爆炸**不伤僵尸**（IZ 常用的"**四杆引雷**"）
- 单个撑杆也能触发**被南瓜套住的土豆雷**爆炸（改版过关有应用）

### 3.5 拦截 bug（106cs 这一帧）

已知 ICE3 生效时间是原速激活后 **105**（减速 210），但正常可拦截时间是原速 **107+**（减速 212+）。
原因：**激活后 106（减速 211）这一 cs 存在拦截 bug**。

| 小鬼与巨人的栈位关系 | 结果 |
|---|---|
| 小鬼栈位 **高于** 巨人 | 此时小鬼存在时间 1cs，**该 cs 内必定成功拦截** |
| 小鬼栈位 **低于** 巨人 | 此时小鬼存在时间 0cs，坐标未初始化（内存垃圾值），下一 cs 才传送到巨人手中 → **本 cs 内概率拦截失败** |

失败表现：**炸黑巨人却没炸掉小鬼**。

### 3.6 舞王

舞王通过**栈位 + 序列号**确认自己的伴舞。若让别的僵尸拥有与某伴舞相同的栈位和序列号，
该僵尸会被误认为伴舞。

应用：新舞夜惊魂（生存无尽）把魅惑伴舞替换为敌对僵尸，**不用女仆秘籍就构建了永动曾**；
我是僵尸中有珍珑《移花接木》。

## 五、实操建议

1. **种植物要有固定顺序**。想复现别人的阵，不只要复现阵图，还要复现**种植顺序**。
2. **别迷信"概率跳过"**。栈位是确定性的，看到"概率"就说明背后有可控变量。
3. **垫材要谨慎**。车底垫在多数情况下不严谨，地刺/窝瓜/三叶草是例外。
4. **做精确拦截时避开 106cs**。要么 105（ICE3），要么 107+（拦截）。
5. **键控/脚本能读栈位**。这是 AvZ 相对手打的核心优势之一（见 `12`）。
