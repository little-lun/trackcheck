## 〇、为什么要有两套

26 版不是小修，是**换了一套骨架**：

| | 2021 版 | **25/26 版** |
|---|---|---|
| 分类数 | 6 类（C/P/S/ch/Cxu/I） | **7 类**（P/S/D/I/F/A/N），字母**只在开头** |
| 白天双冰 | `chX` | **`DX`**（D = Day / Double） |
| 夜间双冰 | `Cxu` | **`Nx`**（N = Night / Nuclear） |
| 夜间单冰 | 无独立类（散在别处） | **`Ax`**（A = Ash） |
| 50s 三冰 | 无 | **`Fx`**（F = Fifty = D+2） |
| 前后缀 | 松散约定 | **成套规则**（复用型 / 时长不变型 / 时长变化型） |
| 参数 | 炮阵：加速1减速2；无炮 C 系：过怪量 | **统一：加速1、减速2**（C 系作历史遗留保留过怪量） |

> 一句话：**旧版按"用什么"分类（card / change / ice），新版按"几冰波 + 多长循环"分类。**
> 新版的两条判据是：**① 冰波数量　② 循环总长**。

## 一、26 版体系（现行）

### 1.1 七个分类（字头）

**字头只在开头出现** —— 这是新版最硬的一条，为了能流畅书写 `P3456`、`S4~6` 这类枚举。

| 字头 | 含义 | 系统 | 冰波数 | 循环 |
|---|---|---|---|---|
| **P** | Pao（炮） | 白天 | 0 | 36s |
| **S** | Single（单冰） | 白天 | 1 | 36s |
| **D** | Day / Double（双冰） | 白天 | 2 | 36s |
| **I** | Ice（连续冰波） | 白天 | 2+ | 非常规（涉复用） |
| **F** | Fifty（= D+2） | 白天 | 3 | 50s |
| **A** | Ash（灰烬） | 夜晚 | 1 | 50s |
| **N** | Night / Nuclear | 夜晚 | 2 | 50s |

**C 系没有废止**，作为历史遗留**归入 P 大类**（`C2`、`C3` 仍叫 C2、C3）。

### 1.2 参数

```
参数 = 减速波数 × 2 + 加速波数 × 1
```
- 白天 36s 节奏：参数范围 **2 ~ 6**
- 夜晚 50s 节奏：参数范围 **4 ~ 8**

> C 系例外：仍用**过怪量**（旧版 §三的解释依然成立）。

### 1.3 三类后缀（新版最实用的部分）

**① 复用无变化后缀（改手段，不改复用）**

| 后缀 | 含义 |
|---|---|
| `io` | 强调 IO 参与输出或作为激活运算量 |
| `d` | 50s 双冰节奏改用**单冰卡 + 存冰**在白天跑，省出模仿者去模仿核/樱桃（实际可写 `-2n`、`-n2a`、`-na2j`） |
| `c` | 加速波**每波用垫材**处理 MJ |
| `-xi` | 用冰代奏/减压，x = 一循环用冰数（x=1 可省） |
| `-xn` | 用核代奏，x = 一循环用核数（x=1 可省） |

**② 循环时长不变后缀（改波形，不改周期）**

| 后缀 | 含义 | 基准 |
|---|---|---|
| `s` | short，冰波**缩短** | 加速波取"参数+1"的节奏时长（S5 的加速波 = P6 的 6s；S4 的 = P5 的 7.5s） |
| `u` | unequal，冰波/加速波**一长一短**，总长不变 | D4 双 18s → 16+19（冰杀矿工）；D5 双 15s → 13+16（挤出 13s 对 7 列冰车） |

**③ 循环时长变化后缀**

| 后缀 | 含义 |
|---|---|
| `xxxx` | 一次循环的精确长度（cs） |
| `#` | **升**：缩短周期 → 参数（压制力）提升。例 D5# = 13,13,6 = 32s |
| `b` | **降**：延长周期 → 参数下降。例 D4b = 20,20 = 40s |

### 1.4 四条书写规则

1. **分类名只在开头**，允许 `P3456`、`S4~6` 这种连写。
2. **前后缀拆掉后必须仍是节奏**（没有裸节奏就不许造衍生名）。
3. 前后缀**不区分大小写**。
4. 轨道里：**加速波代奏冰放 P 后**（`PPI`）；**减速波变奏冰放每波最前**，且只与热过渡放在一起（`IPP-PP`），与激活炸分开。

## 四、对本库两个阵的影响

### PE. 电波钟无炮

```
慢速关：C4io: N | AA' | I | I
```
- **2021 版**：`C4io`（C 系，参数 = 过怪量 4）
- **26 版**：**C 系保留原名**，`C4io` 照写；只是分类上归入 P 大类
- 不变的部分：C 系参数仍用**过怪量**，不用"加速1减速2"

### DE. 双冰六炮

```
轨道：PP | I-PP | I-PP  (6, 15, 15)
```
- **2021 版**：`ch5`（白昼双冰变奏）
- **26 版**：**`D5`**
- 换算注意：本库把"一对炮"写成 `PP`，速查表写成 `P`。
  所以本库的 `PP|I-PP|I-PP` ≡ 26 版 `P|I-P|I-P` ≡ `D5`（标准写法 `I-P|I-P|P` = 15,15,6，同一循环的旋转）

## 五、2021 版体系（保留备查）

<details>
<summary>展开：2021 版的六类与规则</summary>

**六类**：C 系（Cx）、P 系（Px）、单冰变奏（Sx）、白昼双冰变奏（chX，特例 C6i）、夜间双冰变奏（Cxu）、白昼 I 系（Ix）。

## 六、历史沿革（八代）

| 代 | 时间 | 做了什么 |
|---|---|---|
| 二 | 2011-01 | 只分两类：P（全部 36s）、C（全部 50s），假设波长等长 |
| 三 | 2011-02~03 | 新增 `change` 字头，代表各波波长不同的情况 |
| 四 | 2015-04 | `change` 专指含冰波的节奏；另用 `u` 表示波长不等 |
| 六 | 2018-10 | 提出**邻 / 间 / 对**描述夜间双冰；`cxu` 从 `chx` 剥离开 |
| 七 | 2021-10 | 渐强提出用字头区分 36s / 50s，确立 **S 系** |
| **八** | **2025-08-30 / 2026-02-13** | **本版**：字头只在开头；确立 **D / F / A / N**；前后缀成套化；清零 c6i-n/c8i；移除 L 后缀改 s；新增 F 系 |

> 26 版由"**第八代技术党消灭委员会**"讨论定稿。名字很中二，但它就是现行标准。

## 七、五个常见坑

1. **S4 改名错位**：新 `S4` = 旧 `S4*`；新 `S4s` = 旧 `S4`。
2. **D5# 的旧称 `I5` 不是 I 系的 I5**（后者是 14×2.5、5 炮）。
3. **"邻"在 26 版成为默认**：`N7` 就是旧的 `邻C7u`，写 `间N7` 才需要前缀。
4. **`PP` 与 `P` 的差异**：本库习惯 `PP` = 一对炮；速查表 `P` = 一对炮。换算时别把 12 炮写成 6 炮。
5. **C 系没死**：26 版把 C 归入 P 大类，但 `C2` / `C3` / `C4io` 这些名字照用。
