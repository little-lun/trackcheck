## 一、炮位理论（先认清风险，再谈节奏）

炮位 = 春哥的位置。**危险等级 ★ 越多，需要的保护运算量越多。**

| 归类 | 炮位（列） | 风险 | 怕什么 |
|---|---|---|---|
| **九列炮** | 全场地 8、9 列 | ★★★★★ | 一切。跑得快、活得久的都是威胁 |
| **超前置炮** | 前院 6-7 / 7-8，后院陆地 6-7 / 7-8，屋顶 7-8 | ★★★ | 撑杆、海豚、扶梯、小丑 |
| **屋顶前置炮** | 屋顶 6-7 | ★ | 只关心跑得快的 |
| **前置炮** | 前院 5-6，后院陆地 5-6 | ★ | **MJ 伴舞**（靠右会咬炮） |
| **后置炮** | 前院 4-5，后院陆地 4-5 | ★ | **白眼投掷的小鬼**（太早会落到炮上） |
| **拦截炮（鬼位炮）** | 前院 2-3 / 3-4，后院陆地 2-3 / 3-4，屋顶 3-4 / 4-5 / 5-6 | ★★★★ | **小鬼在天上飞** |
| **屋顶后置炮** | 屋顶 2-3 | ★ | 没减速的小鬼 |
| **底线炮** | 全场地 1、2 列 | ★★★ | 前后院：矿工 + 投篮；屋顶：投篮 |
| **海豚炮** | 后院水路 6-7 / 7-8 | ★★ | 潜水、海豚 |
| **安全炮** | 后院水路 1-6 | — | 基本无（被珊瑚啃了就卸载游戏吧） |

### 鬼位炮（新读本第 2 篇）

**定义**：位于小鬼落点上的炮。前院与后院陆路是 2/3 列一带；**屋顶因小鬼落点不同，鬼位变为 4-5 列与 5-6 列**。

**三种保护方式**：

| 方式 | 做法 | 成本 |
|---|---|---|
| **瞬杀** | 红眼投掷前直接四炮秒掉 | 极高（多数阵用不起） |
| **尾炸** | 小鬼落地前炸 3/4 列，P 生效后 ~2.3s | 中；**不能用冰瓜**（减速时机不可控） |
| **空炸** | 炸前场，P 生效后 1.07~1.25s | 中高；压制力最强，可无垫守 7 列 |

## 二、判断一个阵怎么打（四步法）

```
1. 把最高风险的一到两类炮位列出来
2. 选节奏、填操作语言、生成初版轨道，算运算量够不够
   不够 → 改阵，或者"去扣去抢去智商"（旧读本原话）
3. 检查细节：低风险炮位保护了吗？收尾要不要专门设计？蘑菇够不够透支？
4. 开打
```

**压制需求取并集**：一个阵里各炮位对压制的最低要求取并集，才是整阵的最低要求。
操作能达到的运算量超过这个最低要求，阵才能循环。

## 三、新手例阵逐个拆解

### 3.1 传统八炮（新读本第 1 篇的第一个阵）

```
场地：PE
节奏：P4（9s 一对炮）
落点：8 列偏左，炸死伴舞
时机：舞王开始指天时开炮
```
**配置逻辑**：
- 8 门炮在"安全区域"内（剔除矿工/舞王/小鬼/珊瑚的威胁后，刚好 8 个位置）
- 后排冰瓜：减速红眼 + 快速杀死 7 列钻出的伴舞（**防止伴舞啃炮**）
- 后排曾哥：清矿工小鬼

**为什么是 9 秒**：炮 CD 3475cs ≈ 34.75s，8 炮 → 每炮 ~4.3s 可用；
9s 一对炮 = 4 对/36s = 一个循环正好用完全部 8 炮。

### 3.2 3C 八炮（最推荐的无梯八炮）

```
节奏：P4（每 9s 一对炮）
落点：8 列偏左
时机：MJ 刚转身时
后场：2 列四曾（无梯前提下最省的矿工/小鬼防御）
      四个伞叶（无视投篮小偷）
岸路：3 列冰瓜（减速红眼 + 砸 4 列小鬼）
边路：三冰瓜（砸残血红眼 + 压缩减速真空）
```
**弱点**：最怕小丑，其次伴舞。无巨人快速关时，水路顶满的 6 个忧郁菇极易**代替炮弹提前激活刷新**，
节奏越来越快 → 小丑伴舞脱离控制。
**最简单解法**：**挖掉 8、9 列植物。**

> **压缩减速真空**：单冰瓜时红眼可能持续 3s 原速，被减速后与身后的红眼拉开距离，
> 身后出现更大的减速真空。累积起来通常不致死，但"极其难受"。

### 3.3 经典八炮（场地与输出的完美平衡）

```
节奏：P4（9s 一对炮）
改进点 1：岸路 2 列曾 + 梯子 → 无伤处理小鬼
改进点 2：空出底线 → 无伤处理矿工
改进点 3：空出底线后双伞即可覆盖后场 → 冰瓜一个没少
改进点 4：水路空出 8、9 列 → 消除快速关自然输出打乱节奏的隐患（"质变"）
经济：只剩一朵花，但只要不经常换炮绝对够
```
> 旧读本评价：**"就完美而言，经典八炮无与伦比"** —— 8 炮只为刷新服务，
> 没有任何"为放更多炮而做的保护操作"。这是场地与输出的最优平衡点。

### 3.4 经典十炮（P5）

```
节奏：P5（7.2s 一对炮）—— 标准 P5 是每隔 7.2s
落点：8 列正中
时机：海豚声音刚消失时；听到刷新 1s 后可开炮
新增两炮：水路 5、6 列（除海豚和珊瑚外难以到达）
高坚果 ×2 挡海豚
```
**相比八炮**：解决伴舞啃炮（不致死但烦），同时"打起来太简单"。
**代价**：水路无伞，小偷只能炸。

**关末珊瑚处理四法**（关键数据见 `06`）：
```
红字出现后炮闪 5~8 下点冰
红字出现后炮闪 4 下之内在冰上放复制咖啡豆
红字出现后炮闪 8 下发炮
红字消失后 1s 释放灰烬
```

### 3.5 经典十二炮（P6，自然节奏上限）

```
节奏：P6（6s 一对炮）
落点：9 列
波长：6s = 刷新下限，天生无暇
```
**为什么必须 12 炮**：
- 想收伴舞就得炸 8 列 → 但手动可能漏炸巨人/海豚/橄榄
- 想避开伴舞 → 每波僵尸存在时间不得超过 **3.4s**
- 由"相邻两波间隔 ≥ 6s"，得 **12 炮就够**
- 炮弹飞行 3.73s，发炮时该波还没刷出 → **只能预判**

**P6 下 9 列的世界**：红眼不砸 7 列；除红眼/小鬼/小偷/撑杆外其他僵尸**不进 8 列**；
矿工在地下就被炸死；小丑无法开盒；投篮车无法投篮。**即使没有冰瓜，带些垫材也能稳定运行。**

### 3.6 传统四炮（顶满四炮）

```
定位：不把炮当炮用的典型。随便炸一炸冰一冰就能过
经济：四花较充足
植物：边路大喷控丑、冰瓜砸红眼、岸路曾辅助边路
弱点：遇小丑比较虚
```
> 旧读本原话："炮真的是无尽所不可或缺的吗？其实并不。不过适当加炮通常可极大减轻操作压力。"

### 3.7 机械钟无炮（顶满无炮的优化形式之一）

```
定式：7-9 列曾控丑
操作：不能像四炮那样乱来，小丑炸了可能直接崩阵
灰烬控丑：5 路那个大喷 → 让冰道不盖 8 列 → 留出樱桃位与 2 路辣椒成对压制一波小丑
          岸路扔核弹控一波
          剩下靠场地上存的冰（9 列曾控丑法）
```
> 据传已被"电波钟"代替。**请勿在条目里争论机械钟 vs 电波钟**（主观问题去讨论区）。

### 3.8 后退无炮（可较严谨控丑）

```
场地：FE（咖啡豆冲突不存在）
定式：7 列曾控丑，边路大喷杀丑
慢速关：逐波控丑，双冰单核足够
快速关：FE 不能存冰 → "时空兑换"
        上半场：地刺 + 大蒜，把小丑改到 1 路
        下半场：双冰单核樱辣倭轮流上
```
> 结果：一个**可更严格控丑、稳定无尽**的无炮。
