# 06 · 专题：控丑与关键波长

> 小丑是"初学者最常犯问题之一"的来源，也是无炮阵型的头号杀手。
> 来源：维基《生存无尽入门》六(三)(六)、新读本第 2 篇 2.4.2 / 第 3 篇 2.4、旧读本 5.8.1 / 6.6.3。

---

## 一、小丑机制

| 项目 | 数值 |
|---|---|
| 开盒 → 爆炸 | **1.10 s** |
| **早爆型**（占 **5%**） | 刷新后 **4.40 ~ 7.54 s** 开盒 |
| **晚爆型**（占 **95%**） | 刷新后 **13.25 ~ 22.75 s** 开盒 |
| 爆炸判定 | 植物 `x ± 20`，`y 0~+80` |
| 爆炸期间 | **不受冰控制**，但**能被炮/灰烬消灭** |

> **早爆丑只占 5%，却常常是破阵元凶。** 因为它在你还没来得及布置防御时就炸了。

## 二、三条波长红线（记死）

```
加速波 ≤ 5.5 s   → 彻底杜绝小丑（4.4 开盒 + 1.1 爆炸）
冰  波 ≤ 11.5 s  → 无视早爆丑（4.4 + 4.0 冰冻 + 1.1）
冰  波 ≤ 20.3 s  → 无视晚爆丑（13.2 + 4.0 冰冻 + 1.1 = 18.3，取整 20.3）
```

**常用选择**：
| 波长 | 防什么 | 出现在 |
|---|---|---|
| **6.00 s** | 不防丑（但 6s 是刷新下限，加速波最常见） | P6 |
| **7.50 s** | 仍能防加速波小丑（4.4+1.1 = 5.5 < 7.5 不行！） | 注意：7.5 **不防早爆丑** |
| **5.50 s** | 防加速波小丑 | 特殊需求 |
| **11.5 s** | 防早爆丑 | ch6（饕餮之宴） |
| **20.0~20.3 s** | 防晚爆丑 | S4 |

> ⚠️ **易错点**：读本说"7.5 秒波长是最常用加速波波长之一，能杜绝加速波小丑威胁"——
> 那是指**冰波前置**（如 S4 的 `I-PP | PP | PP`，前有 20s 冰波冻住了小丑倒计时），
> 单看 7.5s 本身是不足以防早爆丑的（4.4+1.1=5.5 < 7.5）。**判断时要连同上一波一起看。**

## 三、控丑定式（按曾哥所在列）

**核心判据**：小丑要炸的是**曾哥**（短程、易被炸）。控丑方式取决于曾的位置。

| 曾所在列 | 操作 | 效果 |
|---|---|---|
| **9 列** | 刷新后 **4.4s 内**使冰生效 | 早爆丑仍可能炸曾（概率很小）；不放心在 5 列加喷或 8 列加曾 |
| **8 列** | 刷新后 **4.4s 内**冰生效 + **5 列至少一个喷** | 否则视为控丑不严谨 |
| **7 列** | 刷新后 **3~4s 内**冰生效 + 至少 6 列曾或 4 列喷 | 早爆丑在遇到曾前自爆，晚爆被喷杀 |
| **6 列** | 丑进入曾攻击范围时冰生效；或直接堆火力（4 列曾 + 5 列曾）什么都不做 | 早爆炸不到，晚爆被喷杀 |
| **5 列** | 没好办法 —— 炸死，或堆大喷 | 最尴尬 |
| **4 列** | 预判冰 + 全程减速 + 垫材阻挡 | 条件苛刻，一般不采用 |
| **3 列** | 刷新后约 **4s 内**冰生效，尽量维持减速 | 所有小丑炸空气 |
| **2 列** | 刷新后约 **10s 内**冰生效即可 | 所有小丑炸空气 |

**兼容性**：9、8、7、3、2 列曾的控丑方案互不冲突；6 列与 2 列也互不冲突。

### 精确版数值（来自《技术:无炮研究》，比上表更硬）

| 曾位 | 冰必须在何时生效 |
|---|---|
| **2 列曾** | 刷新后 **1081cs（10.81s）前**，且**不恢复原速** → 全部炸空气 |
| **45 列曾** | ≤ **13.2s** |
| **冰瓜 + 6 列曾** | 约 **13s** 生效（极晚冰），**不可超过 13.2s** |
| **6 列曾** | 刷新后 **8.88s** 生效 → 可冻在 6 列曾范围内 |
| **6 列曾 + 岸路 2 列曾** | 必须在 **8.88s ~ 10.81s** 窗口内生效 |
| **7 列曾** | 刷新后约 **3s** 被减速；单独 7 列**控不住** |
| **4 列曾** | 最左出生 **2268** 晚爆；允许原速区间（cs）：正面 29，前院上炸下 77，前院下炸上 51，后院上炸下 54，后院下炸上 35 |

> 完整八种构型的控丑方案见 `10-维基-无炮研究` 第五节。

### 三种控丑手段

```
① 冰控      —— 预判冰，让小丑倒计时停滞
② AA' 炸    —— 樱桃 + 辣椒，范围覆盖
③ N 炸      —— 核弹兜底
```
顺序不必固定，但**N 之后最好接 AA'**（避免与 I 的咖啡豆 CD 冲突）。

### 控丑定式与节奏的关系（旧读本 6.5.1）

> **定式越靠后，节奏越稳定；越靠前，节奏波动越剧烈。**

| 定式 | 阵 | 节奏 |
|---|---|---|
| 5 列无曾 | FE.无神无炮 | 精准 C3，时间到了用卡杀没自爆的丑 |
| 6-2 列曾 | FE.两仪无炮 | 稳定 C2，偶尔 C3u |
| 6-7 列曾 | FE.后退无炮 | 较稳定 C3-IO ~ C5-IO |
| 7-9 列曾 | PE.神之无炮 | 不稳定 C3-IO ~ C7-IO |

## 四、关末三人组：冰消珊瑚 / 冰消空降

### 4.1 冰消珊瑚（PE / FE）

**时序（精确数据口径）**：
```
红字出现 ──7.20s──► 下一波刷新
                    └─2.00s─► 珊瑚三人组出现
                              └─0.50s─► 开始啃食
```

**冰为什么有效**：冰冻结水面 **3.00s**，冻结期间珊瑚**不生成**。

**四种常用手法**：

| 手法 | 操作 |
|---|---|
| 炮闪点冰 | 红字出现后等炮闪 **5~8 下**点冰 |
| 复制咖啡豆 | 红字出现后炮闪 **4 下之内**，在冰上放复制咖啡豆 |
| 发炮 | 红字出现后炮闪 **8 下**发炮 |
| 灰烬 | 红字消失后 **1s** 释放灰烬 |

**关键常数**：模仿者 3.20s｜咖啡豆 1.98s｜冰与灰烬释放 1.00s｜炮发射 3.75s｜冰冻结水面 3.00s

> 旧帖说"红字后 5.5 秒点咖啡豆"，是**含咖啡豆唤醒时间**的粗算。用精确数据自己排时间更稳。

### 4.2 冰消空降（RE / ME）

- w20 刷新 **2.0s** 后空降三人组登场，下落用时同蹦极。
- 冰可冻结**天空 3s**，若冻结窗口覆盖出场时机 → 完全不出现。
- 也可用叶子保护伞弹走；下落期间会吃冰冻。

## 五、其他僵尸的针对性处理（速查）

### 红眼（6000 血，一锤必杀）
- 别指望纯 IO 打死。标准解：**炸三次 + 约一个路障的自然输出**，或 **炸两次 + 约四个路障的输出**。
- 定住整路红眼：脚下轮流放**两个**快速恢复的便宜垫材（小喷菇/阳光菇/胆小菇/花盆）。
  **原速红眼要四个垫材。**
- 减速红眼：脚下放冰/核并在 **0.70s 内**放咖啡豆（空格暂停是神器）。
- **看到红眼千万别急着连发四炮炸死！**

### 冰车
- 不受冰冻、不被南瓜阻挡、高血、铺冰道（冰道限制灰烬种植）。
- 无冰车抗性的阵：前场周期性释放灰烬 + 地刺。
- 挤冰道：岸路 5 列大喷（让 8 列无冰道，挤出樱桃位）。

### 橄榄
- 多数无炮里存在感低。要求每波**非冰即炸**，否则最前面的植物要套南瓜。

### 小鬼
- 平地主要落 **3 列**，偶尔 2、4 列；天台主要 **4、5 列**，偶尔 2、3、6 列。
- 守底线炮（搭梯）：减速小鬼配**双曾**，原速**三曾**（都放 2、3 列，否则四曾也有几率啃炮）。
- 天台：守底线炮减速小鬼**单曾**够；守 2、3 列炮减速小鬼**双曾**够；守 3、4 列炮需**三曾**。
- 拦截方式：瞬杀（四炮秒红眼前）、尾炸（落地前炸）、空炸（炸前场）。
  - **尾炸**：P 生效后约 **2.3s**，d 生效。炸一路比炸二路好，炸 4 列比炸 3 列好。
  - **空炸**：P 生效后 **1.07~1.25s** 内 D 生效。压制力更强，可无垫守 7 列。**必须炸一路（下半场炸五路）。**

### 矿工
- 十炮以上前场可炸杀全部矿工；求稳要 **十二炮**。
- 后场喷死：**两个忧郁菇**；或一曾 + 冰住矿工；或空出底线（2 列单曾 / 1 列满地刺王）。
- 热过渡可分离开矿工。

### 舞王
- 在 **7 列**召唤伴舞 → 迫使 12 炮以下难以在 7/8/9 列种永久植物。
- 对策：直接炸死；或在 **9 列（有时 8 列）放垫材**逼它提前召唤。
- **预判冰 → 原地召唤**（在 9 列），对前置炮零威胁；反应冰 → 伴舞已走出去，会啃炮。

### 海豚
- 高坚果可挡（**但海豚能跳过 9 列高坚果**！因栈位也可能跳过 8 列）。
- 守非炮植物：南瓜 + 两个忧郁菇基本够。
- **预判冰把它冻在岸上**；反应冰就来不及了。

### 气球
- 四炮 + 冰可稳定炸杀；**无冰需六炮**。
- 六行场地无炮：顶满构型需 **两猫**，后退构型需 **一猫**；不用猫可用三叶。
- **前置炮加猫，气球笑弯腰** —— 陆路有前置炮千万别用猫（气球被击落到炮上）。

### 蹦极（小偷）
- 忧郁菇对蹦极攻击范围极大：落 **2-3** 的小偷，`1-1` 到 `3-5` 的 3×5 方框内都能打到。
- 免疫方式：叶子保护伞，或**六曾火力**。
- **冰杀小偷**：靶子落地到看见小偷之间任意时刻点咖啡豆；火力下限 **两曾**，或 **一曾 + 一瓜 + 任意输出**。

### 投篮
- 十炮以上可完收；四炮配冰也可。**任何阵型都建议用伞守好底线。**
