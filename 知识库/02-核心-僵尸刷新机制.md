# 02 · 核心：僵尸刷新机制

> 这是整个生存无尽头等重要的一块。**所有节奏都是拿来"喂"这套刷新规则的。**
> 来源：贴吧 5194693832（原始出处）、维基《生存无尽入门》六(四)、新读本第 1 篇第 2 章、第 3 篇第 3 章。

## 一、四条基本规则

| 编号 | 规则 | 数值 |
|---|---|---|
| **R0** | 选卡进入场景后，固定 6s 刷第 1 波 | 6.0s |
| **R0a** | w9/w19 刷新后，本波僵尸（除伴舞）全灭**或拖延 45s** → 红字跳出 → **7.2s** 后刷下一波 | 45 / 7.2s |
| **R0b** | w20 刷新后，场上僵尸全灭**或拖延 49s** → 白字跳出 → **5s** 后结束选卡 | 49 / 5.0s |
| **R1** | 任意两波刷新间隔**绝不少于 6s** | 6.0s |
| **R2** | 血量触发刷新：本波剩余总血量 / 本波总血量 < **随机阈值** 时激活刷新，激活后 **2s** 刷出下一波 | 阈值 0.5~0.65(右界不定)，真空 2s |
| **R3** | 每波刷新时额外 roll 一个 25s~约31s 的强制刷新时间，到点必刷 | 25~31s |

**关键细节**：
- R2 的随机阈值**在该波刷新瞬间就已确定**，之后不再变化。
- 该阈值为 `[0.5, 0.67]` 区间随机数，**右边界不确定**（旧帖写 0.67，新读本写 0.65）。这是设计冗余的来源。
- R0a/R0b 的"2 秒"与 R2 的"2 秒"是同一个机制：**刷新真空（刷出下一波前的 2s 空窗）**。

### 一次选卡的固定时间（冰平衡计算的基石）

```
固定部分 = 6 + 52.45×2 + 60 = 170.9 ≈ 171 秒
           ↑    ↑        ↑
         起手  w9/w19   w20 收尾
```

其中 52.45s = 45s 拖延 + 7.2s 红字延迟；60s = 49s + 5s 白字 + 余量。
**这 171 秒是"白送"的拖延时间**，与打什么节奏无关。所有冰平衡计算都从这个数出发。

## 二、时间轴（一次完整选卡）

```
进场 ─6s─► w1 ─?─► w2 ... ─?─► w9 ──►[清完 or 45s]──► 红字 ─7.2s─► w10
                                                                    │
   w10 ─?─► w11 ... ─?─► w19 ──►[清完 or 45s]──► 红字 ─7.2s─► w20
                                                                    │
                            w20 ──►[清完 or 49s]──► 白字 ─5s─► 结束选卡
```

- `?` 处的间隔由 R1/R2/R3 共同决定，**最小 6s**。
- 上 f = w1~w10；下 f = w11~w20。（旗帜波指 w10 与 w20）

## 三、什么时候会刷新？——实战判断表

轨道理论把操作分成"加速"（催化刷新）与"减速"（延缓刷新）。判断依据如下：

| 情形 | 结论 | 说明 |
|---|---|---|
| 一次操作覆盖 **≥4 行** 僵尸（2 个运算量） | **必定刷新** | 这是"2 运算量 = 刷一波"的来源 |
| 一次操作覆盖 3 行（1 个运算量） | 很危险，**多数会刷** | 除非本波很"皮"（高血、慢速） |
| 炸**某一路全部**僵尸 | **几乎必定不刷新** | 但要当心自然输出（IO）补刀 |
| 炸**半场**且有巨人 | 很大几率刷新 | — |
| 有红眼时，六行场地**分离炸两行快速僵尸** | 一般视作**不刷新** | 五行场地分离炸三行同理 |
| 炸**全场** | 视作**一定刷新** | 有红眼时 w10 需再加约一个樱桃的输出才能确保 |
| 无巨人、纯脆皮组合 | 1 个运算量也很容易刷 | 俗称"干脆面" |

> **热过渡** = 用冰的同时附加加法运算（目的通常是炸冰车/矿工保护植物）。
> **冷过渡** = 只用冰，不加运算。这个词在旧读本里叫"节奏过渡"，现已作古，但"热过渡"保留。

## 四、出怪组合分类

判断标准：**有没有巨人** + **快速脆皮多不多**。

| 类型 | 特征 | 典型组合 | 过怪速度 |
|---|---|---|---|
| **慢速** | 有巨人，脆皮少 | 红白杆桶四大龟 | 慢，一波要走很久 |
| **快速** | 无巨人，快速脆皮满天飞 | 梯丑舞豚四大贼 | 快 |
| **变速** | 巨人只出半场 | 上半天不动如山，下半天转进如风 | 半场快半场慢 |
| **极速** | 车丑梯子 MJ 海豚 | 风驰电掣 | 极快，7s 一波 |
| **无巨人延迟** | 车丑铁桶篮球橄榄撑杆气球 | 没巨人也龟 | 慢 |
| **干脆面** | 无巨人、无慢速僵尸 | 单边加速大概率就刷 | 极快 |

### 四大乌龟 / 五大脆皮（新读本第 3 篇）

```
乌龟（右下）：红眼、白眼、铁桶、铁门
脆皮（左上）：舞王、跳跳、小丑、海豚、扶梯
中间派（左下/右上）：其余
```

### 密度上限
- 每波最多 **50 只**（不含伴舞与小鬼）。
- 普僵三大类（普通/路障/铁桶）**至少保留其一**。

### 变速（一个重要现象）
**红眼累计 ≥ 50 只后，非旗帜波不再刷新红眼**（旗帜波 = w10、w20）。
所以在"有红无白"的关里，后半程会明显变快——这就是"变速关"。

## 五、预判 vs 反应

| 手法 | 定义 | 适用 |
|---|---|---|
| **预判炸 / 预判冰** | 估计下一波刷新的时刻，**提前**操作，刷新即生效 | 高精度阵型必用；能让舞王原地召唤、海豚冻在岸上 |
| **反应炸 / 反应冰** | 看到/听到刷新**之后**才操作 | 波动体系；容错高但漏僵尸 |

**预判冰的价值**（新读本第 3 篇实测）：
- 舞王：预判冰 → **原地召唤**伴舞（在 9 列），对前置炮零威胁；反应冰 → 伴舞已走出 7 列，会啃炮。
- 海豚：预判冰 → 冻在**岸上**；反应冰 → 已经跳过水路，炮没了。

> 这是新手阵型"看起来能跑但总被啃炮"的最常见原因。

## 六、刷新相关的三个随机源（旧读本第 6 章）

| 随机源 | 具体表现 | 影响 |
|---|---|---|
| 时间随机 | 小丑爆炸计时（5% / 95% 双峰）、冰冻时长 400~600、植物攻击反应 | 精确操作有暗坑 |
| 空间随机 | 出生点 x ∈ [780, 819]，关底整体右移 40px；僵尸速度差异 | 操作时机线性偏移 |
| 操作随机 | 单边加速、不精确分离、不对称加速（手抖） | 轨道分支 |

**应对工具**：`~`（波动符，表示节奏在两套基础节奏之间摆动）、`+1S`（定态单边加速，见 `03`）、
"双边加速解阵准则"（把一切加速操作升格为双边，再保证弱侧能跑）。
