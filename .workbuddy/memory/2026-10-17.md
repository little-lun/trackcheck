- **为什么搭梯**：扶梯架梯就走不啃 → 南瓜永免维护（对应 `06` 磨损表"扶梯零磨损"）。DE 双冰六炮要搭 **14 个**，全在后场，用户花了两天。
- **三原则**：① 前期满屏种花涨经济，布阵时**有计划铲花**（花是脚手架）② 熬前期靠 临时曾/控制（寒冰射手、冰瓜）/坚果 拖时间 ③ 搭梯要"计划"：分离扶梯 → 保护 → 大蒜引导。
- **大蒜是唯一定向输送工具**：1 路吃蒜必去 2 路、5 路必去 4 路（**确定**）；3 路二选一会浪费扶梯。**这就是通道选 1/3/5 路的原因。**
- **三阶段**：A(0~2F) 纯发育 → B(2~4F) 布阵+前期生存 → C 搭梯。
- **次序铁律**：**先把阵布完，最后才搭梯；冰瓜（紫卡）最后搭** —— 因为种/铲/种紫卡都会让**扶梯消失**。
- **风险**：小丑（可能毁阵→放弃搭梯转压制）、跳跳（带冰让底线曾收）、冰车（地刺，必要时两路刚地刺）。
- **收手**：前 10F 无扶梯 / 20F 未搭完 → 重开。
- **场地差异**：后院 PE/FE 比前院简单（1,2;5,6 皆陆路，去向清楚）。

**DE 双冰六炮具体方案（已写入其研讨笔记 §十二 + 运阵手册 §六）**：
- 0~2F 选卡：花、蒜、伞、南瓜、南瓜(复制)、窝瓜、地雷、曾哥套件；1/3/5 路 8-9 列放蒜，3-7 临时曾收杂（铁桶用雷/窝瓜）；交付：曾伞全就位、南瓜除 1-4/3-4/5-4 外就位、阳光 ≥4000。
- 2~4F 选卡：蒜、双子葵、炮套件、冰瓜套件、火炬、高坚果、双向(有扶梯时)。
- 搭梯次序：2/4 路搭完→3-4 蒜换「南瓜+双向」搭 3 路；再搭完→铲 1-4/5-4 蒜搭本行；1/5 路冰瓜最后。
- **留空 1-4/3-4/5-4 的原因**：那是大蒜位 + 扶梯过道。
