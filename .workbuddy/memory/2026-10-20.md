## 修 `启动出怪沙盘.bat` 双击报错（三个 Windows 坑）

症状：cmd 里一堆"不是内部或外部命令" + 乱码（用户截图）。三个独立原因：

1. **LF 换行**：bat 是 `\n` 写的，cmd 要求 **CRLF**，于是把多行拼成一行当命令执行 →
   报 `Laptop' 不是内部或外部命令` 之类。**这是主因。**
2. **chcp 与编码不匹配**：文件是 UTF-8，但没 `chcp 65001`（默认 936）→ 中文全乱码；
   而 `chcp 65001` 写在非 ASCII 的 bat 里、又是 LF，会进一步错位。
   现在：UTF-8(无BOM) + CRLF + `chcp 65001` + `set PYTHONUTF8=1` + `set PYTHONIOENCODING=utf-8`。
3. **`SO_REUSEADDR`**：Windows 语义允许第二个 socket 绑同一端口，
   `ThreadingHTTPServer` 默认开着 → 重复双击会静默起第二个实例抢 8765，
   而且"端口占用就打开已有实例"的分支永远不触发。
   新增 `class Server(ThreadingHTTPServer): allow_reuse_address = False`。

验证：端口占用路径 exit=0 且不 pause；全新启动路径 8799 返回 200。
注意：WorkBuddy 环境自带 `PYTHONUTF8=1 / PYTHONIOENCODING=utf-8`，
从资源管理器双击时没有这两个变量，所以**必须在 bat 里显式设**。

## setup.exe 支持修改安装目录（第 16 轮）

用户："setup.exe 需要一个修改安装目录的功能。"

- 不能用 tkinter（这版 Python 没 tcl/tk）→ ctypes 调 `shell32!SHBrowseForFolderW`（原生浏览文件夹）。
- 三个坑：① 结构字段要用 `c_void_p` + `cast`（写 LPWSTR 时 buffer 赋不进去）；
  ② `lParam` 是 LPARAM 不能给 None → 给 0；③ 先 `OleInitialize` 否则新式界面不生效。
- 默认目录还没建 → `SHParseDisplayName` 只认已存在路径，必须**往上找最近的已存在祖先**当起点，
  否则对话框会开在"此电脑"（第一版就踩了，测试时装到 `C:\Users\<me>\TrackCheck`）。
- `normalize_dir()`：选 `D:\Tools` → `D:\Tools\TrackCheck`；选的就是 `…\TrackCheck` 原样。
- 卸载必须认自己：`winsetup.app_dir()` 用 `sys.executable` 所在目录，写死默认目录会在改装后卸不掉。
- 命令行：`/S` 静默、`/S /D=<程序目录>` 指定目录（原样用，不追加）。
- 自测：枚举窗口 + `WM_COMMAND` 驱动 MessageBox/浏览框（IDNO/IDOK/IDCANCEL），
  验证 取消→返回 None 无残留、确定→返回选中路径、`/D=` 自定义目录装/跑/卸全通、
