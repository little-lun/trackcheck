   控丑空窗、冰慢一拍、蹦极无冰的**结果都是致命 L0**；
   若造成它的原因人类能设法阻止（只差一个冰、卡差两秒、换个顺序）→ 降 **L1**；
   即便最优假设人类也做不到 → 保持 **L0**。
   实现 `_squeeze(r,w)`：① 波首有存冰 → 能；② 某卡 ≤3s 就好 → 能；③ 有卡"好"却没排上 → 能；
   ④ 存冰 0 且冰/樱/辣/核全在 CD 深处 → 人力不可及 → L0。
   变速 w19 实测判 L1（"波首还有 1 个存冰没点"）。
2. **边路大喷死 = L2**（不在设计中，合理运阵绝不会死，但有冗余能补），
   **南瓜磨损 = L3**（必然发生，选卡带南瓜就是设计来吸收它的预算）。
   L3 的定义从"边路大喷"改成"设计内的预算"。
3. **阵线取整波最深处**：`_snap_tick` 从覆盖改为累积 min；
   阳光/存冰/卡槽 CD 也拆波首/波末（`sun → sun_end`、`ice → ice_end`），hover 显示双值。
   原因：波末僵尸常已死光，快照看不出危险。

文档/工具：`_md()` 只处理 `**粗体**`；最终输出统一替换一次（单行内，不误伤 script）。
四档 8 局：慢速 15.39s/存冰4.0/L3、变速 11.95s/3.8/L1、快速 9.39s/2.0/L3、极速 9.04s/4.0/L3。
