## 任务（用户两条）
1. **重做刷怪时间机制**（原 R1/R2/R3 随机模型整套换掉）。
2. **桌面版要真正的本地 app**：现在双击 exe 还是打开浏览器，要求独立 app UI，

## A. 刷怪时间（用户口径，逐字）

> 开始后 6s 刷出 w1。
> 常规波：本波刷怪后**等 4s** → 接着的 **27s** 里统计本波僵尸总血量，掉到
> **原本波总血量 65%** 或 27s 结束 → 再**等 2s** 刷下一波。
> 长间隔（w9,w19 → 旗波）：等 **45s 或全灭** → 红字 *a huge wave of zombies is approaching*
> 显示 **7.2s** → 红字消失后旗波刷新。
> 结束（w20 → 本 2F 结束）：等 **49s 或全灭** → 白字 *more zombies approaching*
> 显示 **5s** → 进选卡界面（= 模拟结束）。

实现：
- `data.py` 删 `R1_MIN_GAP` / `R2_VACUUM` / `R2_CALIB` / `R2_THRESHOLD` / `R3_HARD`，
  加 `WAVE_HOLD=400` / `WAVE_WINDOW=2700` / `WAVE_VACUUM=200` / `WAVE_HP_THR=0.65`。
- `engine._tick_refresh` 常规波分支重写：`age >= WAVE_HOLD` 才开始判血线；
  `trig` 之后 `WAVE_VACUUM` 再刷。波长 = 4 + min(27, 掉到 65% 用时) + 2 → **6~33s**。
- `spawn_wave` 的 meta 里 `thr` 固定 0.65（报告还显示它）、`hard` = 3100。
- w9/w19/w20 三段数值本来就对，没动。

## B. 桌面版原生窗口

- 新增 `tools/trackcheck/desktop/appwin.py`（入口，代替 `launcher.py`）：
  仍起 `127.0.0.1` 服务，但用 **pywebview** 开原生窗口（Win 上是 Edge WebView2）。
  `private_mode=False` + `storage_path=%LOCALAPPDATA%\TrackCheck\webview` → localStorage 落盘。
- `app.py` 抽出 `create_server(host, port) -> (srv, url)`，网页版/桌面版共用。
- JS 桥 `window.pywebview.api`：`save_file / open_file / save_bytes / app_paths / open_folder / quit`。
  页面侧统一助手 `TCFILES`（桌面 → 原生对话框；网页 → Blob 下载 / input file）。
- ui.py 新增「设置 · 本地文件」面板：导出配置 / 导入配置 / 打开数据目录；
  出怪列表的导入导出、报告 PDF「另存为」全部走 `TCFILES`。
- `build_win.build_app()`：入口换 appwin.py + `--collect-all webview / clr_loader / pythonnet`，
  exe 从 8.35MB → 12.7MB。pywebview 起不来时自动退回浏览器模式并弹 MessageBox。

### 踩的坑（记住）
1. `pip install pywebview` 之后 **PyInstaller 掉了**（`No module named PyInstaller`）→ 重装。
2. onefile 打包后**父进程没有窗口句柄**：`Get-Process TrackCheck-0.3.25` 会看到两个 PID，
   只有子进程（dev 里是 28260 那种）才有 `MainWindowTitle`。
3. **WebView2 是硬件合成层，`CopyFromScreen` 截不到内容**（截出来是桌面/视频）——
   验证方式改为：窗口标题 + HTTP 200 + 子进程里有 `msedgewebview2.exe`。
4. i18n 检查器抓的是**整条 JS 字面量**：路径里的 `\\` 会被当转义，键对不上 →
   干脆改写文案避开反斜杠。
5. ★★ **`js_api` 会把解释器卡死**：页面里第一次调用 `window.pywebview.api.*` 之后，
   整个 Python 侧不再响应（连 8765 上的 HTTP 都不回字节），窗口却还好好的。
   `CreateFileDialog` 也归这条桥管，所以一并放弃 →
   改成 **HTTP `/api/native` + `native_dlg.py`（comdlg32 ctypes）**。
   这段教训值得记：pywebview + pythonnet 只当"显示器"用，别让它回调 Python。
6. `OPENFILENAMEW.lpstrFile` 必须 `ctypes.cast(buf, ctypes.c_wchar_p)`；
   写成 `POINTER(c_wchar)` 会 `TypeError`。
7. 验证原生对话框不靠人点：起个线程 `EnumWindows` 找 `#32770` 窗口，
   `PostMessage(WM_COMMAND, IDCANCEL)` 自动取消 → 确认"弹出来 + 干净返回 None"。
