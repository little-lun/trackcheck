### ★ PvZ Tools 旧格式破译（关键结论）
```
钉耙行, ID 行 列 awake f5 f6, ...
```
- `ID` = **十六进制 SeedType 直接值**（`2A`=42 忧郁菇、`10`=16 睡莲、`2C`=44 冰瓜、`29`=41 双子花、
  `2B`=43 香蒲、`A`=10 大喷菇、`E`=14 寒冰菇、`25`=37 保护伞、`21`=33 花盆）—— **不是 index+1**
- 第 4 位 `awake`：只对蘑菇有意义（忧郁菇/大喷菇=1，存冰寒冰菇=0）
- **`1E`(30) = 南瓜壳；`30`(48) = 梯子**（不是模仿者！）
  依据：`30` 恰好只出现于 1-2/1-3/2-2/2-3 四格 = 本库四个梯子南瓜；「模仿南瓜」只可能一张
- 条目顺序：底座 → 主植物 → 南瓜 → 梯子
- 局限：**不支持模仿者主植物与墓碑**（encode 抛错提示切 toolkit）
- **顺手修的坑**：`忧郁菇` 漏在 `data.MUSHROOMS` 里 → awake 写成 0、与工具对不上；
  补进去之后用户串**解码 40 格 → 再编码逐字一致（1111 字符）**
- 该串与 `CFG.ARRAY` 只差 3-4/4-6 两格缺睡莲（源串本身没写，疑似模仿睡莲，旧格式表达不了）；
  `fix_bases` 会自动补上

### 命名 `[场地].名字`
`plan.name` 只存**裸名**，`full_name()/bare_name()/plot_prefix()` 现拼；换场地前缀跟着变；
阵解库下拉、导出文件名、报告头都显示全名；示例裸名从 `PE.电波钟无炮` 改成 `电波钟无炮`
