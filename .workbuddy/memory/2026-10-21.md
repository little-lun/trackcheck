
## v0.3 阵解栏：选卡 / 全场判定 / 简化救场 / 快捷布置 / 批量 / 匹配（第 17 轮）

用户 9 条需求 + 2 条调整。核心是**统一说法**：阵解里只写植物名。

**统一说法**：点存冰 → 在某格**种咖啡豆**；补存冰 → 在某格**种寒冰菇**；
查存冰数 → `plant_count`（场上某植物数量）/ `cell_is`（某格是什么植物）。
- 积木目录全部改成植物名（毁灭菇/寒冰菇/咖啡豆/小喷菇/花盆/…），保留特技 `窝瓜压车`。
- 引擎 `do_action` 入口 `_OP_ALIAS` 兼容旧名；`_norm_act` 也映射 → 报告层统一看到植物名。
- `Sim.plan_ctx()` 新给 `plants`（含"存冰算寒冰菇"的映射）与 `cells`。
- `寒冰菇` 的 aim：`[r,c]`=该格（存冰位→补存冰，普通格→即冻）/ `"stock"` / `"temp"` / null=即冻。

**新增能力（引擎）**：`Sim.stall_at(rc, cards)`（在指定格下垫材）、`plan_ctx()`、
`activate_ice()`、`globals_tick`（`Sim(globals_tick=)`，run 循环里每 tick 调）。

**plan.py**：`deck`(10 槽)、`globals[]`、`rescue_simple{resources,targets}`、
`quick_layout/parse_track`、`shift_waves`、`batch_edit`、`pick_rows`、`spec_text(plan|spawn|config)`。

**UI**：三标签 ① 出怪 ② 阵解 ③ 运行（取消沙盘页开始按钮）；阵解库多套 + 匹配表；
选卡栏；每波勾选框 + 全选/反选/前移/后移/复制/粘贴/清空/撤销（40 步）；
所有 JSON 处有小 `i`（模态框可复制/下载 md）。
`role_of`：只有 w1 起手，w2/w11/w12 归常规（引擎 role 同步）。

**踩坑**：默认阵解里 `咖啡豆 @3-2` 写死格子 → 3-2 没冰时每次断裂（seed0 165 次）；
改 aim=None 自动挑装满的存冰位。简化救场若每 tick 空转也会刷成吨"断裂"
→ 加 `every`(默认30cs) 失败退避。最后 断裂 0、冰 4/4、15.68/15.71/15.17s。

**打包 bug**：onefile 下 `__file__` 在临时目录，`plans/` 存了会丢
→ `_plans_dir()` 在 frozen 时用 `%APPDATA%\TrackCheck\plans`。

实测：四档内置轨道逐字未变（15.36/15.65、11.76/12.67、9.19/9.20、8.89/9.17）；
快捷布置 17 波；平移/复制/粘贴/清空/撤销全通；选卡过滤生效；匹配后同一队列里
慢速A 走积木版 15.68s、快速B 走内置 9.19s。产物 v0.3（web 16.12/0.50MB、setup 23.3MB）。
**修复（用户反馈）**：批量操作的勾选框点了不显示勾。
原因：勾选框在 `data-act="selWave"` 的行里，click 冒泡到行 → selWave → `plRender()` 整页重画，
把刚打上的勾抹掉（change 事件还没来，元素已被替换）。
修法：`PL_ROOT` click 处理器**先拦 `input[data-mark]`**，手动 `PLAN.marks.add/delete` 后只调
`plRenderWaveList()`（不整页重画）并 return。顺带给勾选行加 `.marked` 视觉（浅蓝底 + 左侧色条），
平移后保留勾选（可连着挪），粘贴/清空后才清空。实测：单击/取消/全选/反选/清空、平移两次、撤销两次全对。

## 版本编号规则（用户 2026-10-21 22:48 指定）

对外版本 = `0.x`（只在正式打包时递增）；**同一次发布里每改一处记 `0.x.n`**
（0.2 → 0.2.1 → 0.2.2…），`0.x.0` = 打包基线。
已写进 `MEMORY.md`（长期记忆）、`tools/trackcheck/README.md`（"版本编号规则"小节）、
`tools/trackcheck/发布说明.md`（六、版本 开头）。
以前"第十七轮/第十八轮"只当时间线称呼，不再当版本号。
目前状态：产物仍是 `0.2`（= 0.2.0 基线），**下一处改动起记 0.2.1**。
