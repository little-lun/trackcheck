## 3. 阵型字符串两套格式

- **PvZ Tools（旧，明文）**：`场地号, ID 行 列 state f5 模仿flag, …`
  - `ID` = **十六进制 SeedType 直接值**：`2A`忧郁菇、`10`睡莲、`2C`冰瓜、`A`大喷菇、`E`寒冰菇、
    `1E`南瓜、`30`梯子、`25`伞、`29`双子、`2B`香蒲、`2F`炮、`21`花盆、`23`咖啡豆、`31`钉耙、
    **`32`墓碑**；主植物 `plant = ID + 1`。
  - 顺序：底座 → 主植物 → 南瓜 → 梯子。⚠️ re-encode 会**多出**原串没写的睡莲 →
    不是逐字往返，别把"内容一一对应"说成"逐字一致"。
  - **★ 首字段是场地号**（pvztoolkit `lineup.cpp` 实锤）：`0`PE `1`FE `2`DE **`3`NE** `4`RE `5`ME；
    钉耙是单独条目 `0x31`。⚠️ 本库 `decode_tools` 把首字段当钉耙行、**且不认识 `0x32`**
    （含墓碑的阵会静默丢碑条目）—— 已上报，未修。
- **PvZ Toolkit（新）**：RFC1437，Base64 → 整段（含 RS 字节）异或 0x54 → zlib + RS
  （RS 放错在异或外面会得到 rake 恒 5 / 场景恒 6）。
- 工具 `layout.py` 两套都支持，设置页选、导入自动认格式。

- **紫卡基础价/实际单株价**（含基座）：忧郁菇 150/225、香蒲 225/250、冰瓜 200/500、双子 150/200、

- **绿卡易错价**：窝瓜 50、大喷菇 75、双发 200、咖啡豆 75、毁灭菇 125、辣椒 125、樱桃 150、
  南瓜 125、伞 100、荷叶 25、大蒜 50、小喷 0、花盆 25、三叶草 100、西瓜 300。
  （完整 40 张见 `docs/知识库/05` 第十二节）
- **无尽紫卡涨价**：第 n 株 = 基础价 + 50(n−1)；种 n 株 = n×基础价 + 50·n(n−1)/2。**绿卡不涨。**
- 白天用一次核 = 200（毁灭菇 125 + 咖啡豆 75）；点一次存冰 = 75。
- **场外区**：第 10 列（及第 0 列）属场外。可伤条件 = **防御域左端 ≤ 800** → 普僵 x ≤ 764、巨人 x ≤ 800。
  "在场外"≠"打不到"，但**打不完整**。
- 读轨道**先读卡 CD，再读运算量**（顺序常被咖啡豆 CD 逼出来，如 C4io 的 N|AA'|I）。
- **忧郁菇对蹦极判定框是 3 行×5 列**（对普通僵尸只有 3×3）→ 落到 2-3 的小偷，1-1 到 3-5 都打得到
  （"**2 曾杀蹦极**"的机制原因）。蹦极停留 300cs、抓取 63cs。
- **投篮（投石车）落点在底线（1、2 列）**，两条波长红线：加速波 7.46s / 冰波 19.29s。
  伞罩住底线即免疫 → "怕不怕投篮"看**底线有没有伞**，不是波长够不够短。
  （模型互证：473+74+199 = 746cs = 社区"加速波无伤上限 7.46s"）
- **伞覆盖 3×3 且含自身格**。放第 2 列才能罩住第 3 列关键植物；放第 1 列只有 4 格有效面积。
- 无炮的冰是稀缺资源，按**可逆性**排序花：不可逆损失 > 可逆磨损 > 节奏舒适度。
- 红字 = "a huge wave of zombies is approaching"（旗波将至）；白字 = "more zombies approaching"（2F 结束）。

## 7. ★★ 判定与伤害模型（机制核心）

### 7.1 攻击判定 = 「框相交」
- 不是"僵尸中心在范围内"，是植物**攻击框** ∩ 僵尸**受击框**非空即命中。
- 受击框（相对 z.x 的 `off + width`）：**普通 `(+10,42)`、巨人 `(-35,70)`、冰车 `(0,80)`**
  （0.2.12 起；0.3.2 模型清单记为 `(-10,100)`，**待统一**）。
- **★ 判据是"位置"不是"体型列数"**：普通站 x 列**正中央**只吃 x−1/x/x+1 三列，走到**左半边**才吃四列；
  **巨人正中央就已跨格** → 正中央就四列。⚠️ `off` 必须 > 0 才能复现"正中央 3 列"。
- **y 方向（0.3.22 统一）**：受击框 y 高度 = **一整格**（`fld.gap`），与格子上下界重合。
  格 `y行x列` = `[y-1,y]×[x-1,x]`，格心 `(y-0.5,x-0.5)`；px 换算 格心 y = `plant_y + 40`。
  → R=115 的炮纵向**只盖 3 行**（115/85=1.35）。
- ⚠️ 旧模型 `[x−36,x+36]`（宽 72 居中）**是错的**（僵尸一出生就进所有射程）。
- **x 基准偏移 57px**：wiki"左界 = x+36"里 x 是**僵尸精灵图基址**，植物 x 是**格中心**，差 57px
  （=36+42/2）。照抄会让输出低估 38%。

### 7.2 AoE 与 dps
- **★ 永远不要用"总血量 ÷ dps"判断 AoE 阵可行性**：曾哥对 3×3 内**每只各打全额 80**、大喷前方 4 格各打 20，
  **都无衰减** → 僵尸越多总输出同比放大，**每只受到的 dps 不变**。
  唯一判据：`T_kill（血÷该点 dps） ≤ T_move（走到该路最靠前的 CORE）`。
  实测：2 路 21 只 → 41.0s 全灭；32 只 → 42.9s（数量 +50%，时间 +5%）。
  → 2 路 4 级 IO"红眼来多少都能杀"；5 路 3+ 级 IO 弱一档（21 只跑掉 3 只），需 5-7 一张垫材。
- **忧郁菇**：193cs/轮、4 次命中（延迟 74/102/130/158）各 20 伤 → **41.45 dps/只**。
  4 次必须**分开结算**（`pending` 队列），合并成"一次 80"会让死亡时刻/溢出/补位全错。
- **攻击间隔**（[精 5.1]）：大部分 1.36~1.50s｜投掷类 2.86~3.00s｜**忧郁菇 1.86~2.00s**｜地刺王 1.01s
- **冰瓜溅射**：574/n（n **不含被直击那只**），取整，**上限 26、下限 1**；直击忽略飞行时延。
- **灰烬圆形判定**：(Δx)²+(Δy)² ≤ R²；**纵向两套 y**（僵尸 50+85(r−1)，植物 80+85(r−1)，**差 30**，
  正是"2 路的核能炸到 5 路巨人"的原因）；距离算**圆心到受击框最近点**。
  [精 六] 樱桃/毁灭菇圆心 = **(x+40, y+40)**；炮 R=115、N R=250。
- **炮是点哪打哪的迫击炮，落点没有射程限制**（准星可到草坪任意格）。
  曾把 R=115 误当"瞄准射程 ±1.44 格"——已撤销。
- **炮 AoE = R115 圆，框相交即命中，每只各吃 1800 无衰减**（实测命中 21 只 = 37800）。
- **炮占两格，头/尾定名（2026-10-28 定，维基+阵图互证）**：记在 `c` 列 → 占 `c`、`c+1` 两格；
  **炮头 = 前轮 = `c+1`（右侧那格）**、**炮尾 = 后轮 = `c`（左侧那格）**。
  【维】"墓碑可以在炮头生成；炮后轮可以有花盆也可以无；若炮前轮有花盆也可把它顶掉。"
  → NE.压碑五炮实测"5 列花盆 + 6 列碑"即"后轮盆 + 前轮碑"，与原文完全吻合。

### 7.3 僵尸侧机制
- **二类防具**（`SHIELD2`）：铁门 1100 / 读报 150 / 扶梯 500。**在 AoE、投掷子弹下不起作用**
  → 冰瓜/大喷/忧郁菇/溅射/灰烬/炮/窝瓜/篮球 一律 `pierce=True` 绕过。
  一类防具（路障/铁桶/橄榄盔/矿工帽）**不单独建模**，折进总血量等价。
- **磁力菇只吸金属**（白名单）：铁桶、铁门、橄榄头盔、小丑盒（掐引信永久不炸）、矿工镐（立即出土向左走
  不眩晕）、跳跳杆（变步行 3.8s/格）、梯子。**报纸不吸**（纸）。
- **减速分两类**（wiki 口径）：**匀速**（潜水/跳跳/投篮车/气球/挖掘中的矿工/冲锋海豚/冰车**免疫**）
  → 只有位移 ×0.4、动画不变；**非匀速**（两条腿走）→ 位移和动画进度都 ×0.5。
  ⚠️ 匀速与否**分阶段**：矿工只在 `dig` 匀速、海豚只在 `run` 匀速。
- **矿工**三段：`dig` 地下 1.2s/格（**只吃灰烬 P/N/A/A′**，窝瓜/冰瓜/喷雾都不行）→
  `stun` 出土 130 + 眩晕 350 → `walk` 向右 7s/格从背后啃。地下时**不能被选为目标**。
- **小丑不啃植物**（盒子是独立计时器，到点原地炸）——曾造成"小丑啃掉 5 列炮"的假崩阵。
- **投篮车不啃植物**：碰到植物停在前方，只扔篮球。
- **巨人**：420~590cs/列是**正常速度随机区间**（每只独立抽）；必须打满血才解除威胁（1 血与 6000 血威胁相同）；
  被垫材钉住时长 = **330cs**（= 砸击周期，不是减速 600）。
- **行走速度以《僵尸时序表》(2024/08/26, Crescendo) 为准**。用法：**只用"同一种植物、不同列"求差**
  （行标签植物不同不可比）。啃食点 45 → **34**；另有起步偏差 `SPAWN_ADJ_CS`。
- **同一波同一时刻生成**（无碰撞箱，允许重合）；每波严格 ≤ 50 只（旗帜额外插入，**占 51 位**）；
  出怪严格按原版列表顺序（影响 LastPicked 选行）。
- **★ 蹦极不能被偷玉米炮**：英文维基 `Bungee Zombie` 原句 "Cob Cannons cannot be targeted by
  Bungee Zombies, as they are too large to be carried"（百度百科一代条目同义："不包含玉米加农炮"）。
  → **炮阵的炮不需要伞覆盖**；且**蹦极仅在旗帜波生成**（一个 2F 只有 w10/w20 两次）。
- **小鬼落地（平地）主要在 3 列**，偶尔 2、4 列；天台主要 4、5 列。（不是 6~9 列，别记反。）

### 7.4 阵解符号（硬性）
- `c`=垫材（小喷菇，轮换 小喷菇/花盆/阳光菇/胆小菇）；`C`=地刺；`C'`=地刺（不是花盆）；
  `a`=窝瓜（`W` 兼容）；`I` 冰、`N` 核、`A` 樱桃、`A'` 辣椒。
- 炮种 = **节奏角色**：`P`主炮 / `S`同步炮（须锚一个 P）/ `B`提前炮 / `D`延迟炮 / `d`尾炸炮 / `p`铲种炮。
  落点策略独立：`front` / `dyn` / `imp` / `tail`。
- 冰变奏三字符复合记号 `PI1/PI2/PI3/cI4`，`_track_chars` 必须**从长到短**匹配。
  **ICE3 必须警告（有效时机 1cs）、ICE4 必须警告（无可用阵型）**。
- `-`（刷新符）：**`-` 前 = 刷怪即刻**（不进绝对时间轴），**`-` 后 = 锚定上一个主运算量 + 本拍波长**。
- **波长串 `gaps[i]` = 到第 i 拍的间隔**（case 实测口径，N6s = 900/900/1800/1800）。
  单位自动识别：默认秒，最大项 ≥100 或最小项 ≥60 → 整串按 cs。

### 7.5 场地、冰道、大蒜
- **冰道**：是**格子属性 + TTL**，只由**辣椒烧化**或**长间隔自然融化**清掉。
  ⚠️ **冰车被消灭时冰道不随之消失**（v4.1 写错过，已撤销）。
- **冰车车头/车尾差一格**：车头 `z.x` = 碾压判定前沿；**车尾 `z.x+80` = 冰道覆盖前沿**。
  → 车头到 8 列(600) 时车尾(680) 才铺 9 列；窝瓜在车头 ≤720 时引爆即可保住 5-9 核坑。
- **灰烬种下即免疫碾压**；已被咖啡豆唤醒的核不被车碾压，巨人砸只会使其立即触发。
- **大蒜**：陆路僵尸吃大蒜不会去水路，反之亦然。PE 中 **2-9 大蒜驱赶去 1 路，5 路大蒜驱赶去 6 路**。
  ⚠️ 极速关若出怪**有冰车或投篮车就不带大蒜**，改在 2-7/5-7 种大喷提高结构丑抗。
- **w20 三人组**（忽略时延，视为特定区域突然出现）：**PE/FE 珊瑚区 = 水路 6~9 列**；

### 7.11 炮序（手操炮阵的几何，2026-10-29 立项）

→ 详见 `练习/00-炮序专题.md`。三句话版本：
**① 预选律**：每组头一发用**最远**的炮，提前选中停在落点待命（长距离藏进等待期）；
**② 中继律**：第二发用**落在两落点连线上**的炮（`argmin dist(t₁,c)+dist(c,t₂)`）；
**③ 同位律**：复用炮两发落点尽量靠近。硬参数【码】释放→爆炸 **378cs**、CD **3475cs**、落点无射程限制。
三阵要害：**DE 的 3-1 底线炮最贵（560 vs 240px）→ 只当预选、绝不当中继**；
NE 五门等距 → 中继取**中间行**；FE 炮最远 → **先 1 列、后 3 列**。
**★★ 定律 0（2026-10-30，优先级最高）：先定可行域，再谈最短路** ——
落点/炮不一定是自由变量（RE：上界之风把底线炮钉死 2 路、平地炮钉死 4 路，不可互换）。
约束只多花 **5.0%**；红利是五拍都瞄同一条水平线。→ 先问「哪些炮能打哪些落点」，再问「怎么排最短」。
**第四阵 RE.天台十炮**：底线炮 520~624px vs 平地炮 120px = **4.40×**（四阵最极端）
→ **顺序反了多走 38%**。★ **斜坡对角律**：最小值在**对角线**（H1→T2… 全 520px）而非同行（527.7）
→ **1 列 r 行炮当 8 列 r+1 行瞄**。★ 5 拍用完 10 门 → 总和恒定，配对只削峰：**极差 238.8 → 79.8px**。
→ 完整定量见 `练习/00-炮序专题.md`。

### ★★ 7.11.1 波长串口径（2026-10-29 校准）

> **波长串第 i 项 = 「到达第 i 拍」的时长**（不是「从第 i 拍出发」）。
> 拍1=0，拍2=g₁，拍3=g₁+g₂…；**g₀ 只用于「末拍 → 下一循环首拍」的回绕**。
> 邻N7 `(18,18,6,6,6)` → 拍时刻 **0/18/24/30/36**。

- ⚠️ 曾把 g₀ 当"拍1→拍2"，**错位一位** → 造出"N6s/邻N7 需 6 门"的假矛盾。
  **四套阵解全部排得开**（DE.D5 ✅ / FE.P3-n ✅ / FE.N6s ✅ / NE.邻N7 ✅）。
- **DE.D5** `(6,15,15)` 拍 `0/15/30` → 拍1 前只有 g₀=6s（最短）→ **3-1 编入拍2，不可编入拍1**。

- ★ **36s 魔数**：四套解每门炮复用间隔**都恰好 36s**（54=36×1.5）。CD 34.75 →
