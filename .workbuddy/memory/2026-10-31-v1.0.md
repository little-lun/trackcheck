## GitHub Release（已完成）
用户装了 GitHub CLI（`C:\Program Files\GitHub CLI\gh.exe`，2.103.3），但 `gh auth status` 显示未登录。
**不需要用户点任何东西** —— 用 git 自己存着的凭据喂给 gh：
```powershell
# 1) 从 Windows 凭据管理器里取已有 token（GCM 存的）
"protocol=https`nhost=github.com`n`n" | git credential fill    # → username / password(=token)
# 2) 非交互登录（PowerShell 不支持 `<` 重定向，要用管道）
Get-Content -Raw $tmp | & $gh auth login --with-token
```
拿到 token scopes：`repo, workflow, gist, notifications, read:org, user, read:gpg_key, write:public_key` —— 够建 Release。

```powershell
gh release create v1.0 --repo little-lun/trackcheck `
  --title "trackcheck v1.0 · 第一个正式版（1.0.0）" `
  --notes-file releases/v1.0/release-body-v1.0.md --latest `
  dist/trackcheck-1.0.0.html dist/trackcheck-1.0.0-web.html `
  dist/trackcheck-v1.0-setup.exe dist/更新日志-v1.0.md
```
→ https://github.com/little-lun/trackcheck/releases/tag/v1.0 （draft=false、pre=false、latest）

### 坑（务必记住）
1. **中文文件名传给 gh 会被吞成 `-v1.0.md`**（PowerShell → 进程参数的编码损失）。
   补救：把文件复制成 ASCII 名（`CHANGELOG-v1.0.md`）再 `gh release upload`。
2. `gh release delete-asset` 删以 `-` 开头的名字必须先加 `--` 分隔符，否则报
   `unknown shorthand flag: 'v'`。
3. 校验下载链接：`Invoke-WebRequest -Method Head https://github.com/.../releases/download/v1.0/trackcheck-v1.0-setup.exe`
   → 200 + Content-Length 29363401（28 MB）。

最终附件：`trackcheck-1.0.0.html`(16.8MB) / `trackcheck-1.0.0-web.html`(1.2MB) /
`trackcheck-v1.0-setup.exe`(28MB) / `CHANGELOG-v1.0.md`(4.7KB)。
