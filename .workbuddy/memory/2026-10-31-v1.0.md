## GitHub Release（已完成）
用户装了 GitHub CLI（`C:\Program Files\GitHub CLI\gh.exe`，2.103.3），但 `gh auth status` 显示未登录。
**不需要用户点任何东西** —— 用 git 自己存着的凭据喂给 gh：
```powershell
# 1) 从 Windows 凭据管理器里取已有 token（GCM 存的）
"protocol=https`nhost=github.com`n`n" | git credential fill    # → username / password(=token)
# 2) 非交互登录（PowerShell 不支持 `<` 重定向，要用管道）
Get-Content -Raw $tmp | & $gh auth login --with-token
```
拿到 token scopes：`repo, workflow, gist, notifications, read:org, user, read:gpg_key, write:public_key` —— 够建 Release。

```powershell
gh release create v1.0 --repo little-lun/trackcheck `
  --title "trackcheck v1.0 · 第一个正式版（1.0.0）" `
  --notes-file releases/v1.0/release-body-v1.0.md --latest `
```

# 1.0.1（2026-10-31）— 表层阵解 · 轨道改成视频剪辑式时间轴

## 用户口径
「模仿视频剪辑 app 的轨道，制作可以编辑的、描述操作的轨道，以时间为横轴。
自动放置波 mark，没有编辑时按最长时间放；有运算量 mark 时按运算量定理自动调整。
把所有操作分为 P mark 与 C mark。有依赖/锚定关系的 mark 用虚线箭头连接被依赖的 mark。
编辑虚线时，虚线起点（指出去）的 mark 的横轴自动调整。
剩下的无需时空锚定其它 mark 的触发器保留不变，而可以通过时空锚定其它 mark 的触发条件移除。」

## 实现要点（全在 `planui.py`）
- 新增 `tl*` 函数族：`tlWaveTimes / tlTimes / tlLayout / tlRender / tlMarkHtml /
  tlDrawLinks / tlInspector / tlAnchorRow / tlSetOffset / tlSetGapAt / tlMakeLink /
  tlAddMark / tlBind`。时间轴**不新增持久字段**，wave mark 由波长串 + 运算量约束**派生**。
- `plRender()` 视图感知：`TL.view==='tl'` 走时间轴（清单视图 `#pl-gridview` 隐藏）；
  切回列表则 `tlInspClear()` 并把 `#pl-wavebox` 还回去。`localStorage['tc.tlview']` 记选择。
- `plTrigKindList(cur)`：时间轴视图里去掉了 `time` / `after` / `after_block` 三个触发器
  （只在该块**已经**是这三者之一时保留当前值），列表视图不删。
- 拖动：拖 mark = `tlSetOffset`（改锚定延时，事件驱动改成 `time`）；
  拖 wave mark = `tlSetGapAt`（反写 `plan.rhythm.gaps`，没有就先物化整串）。
- `engine.spawn_wave` 记 `_block_fired['wN'] = self.t`，让 `after_block id='w7'` 能锚定波 mark。

## 踩坑
1. **波长无限增长**（两处，都要排除）：
   a) 锚定到「后面某一波」的 mark 参与本波运算量 → 波 w 推迟 → 波 5 又推迟，永不收敛；
   b) 已经 `>= T(w+1)` 的 mark 参与本波约束 → m1 锚到 w2、m2 链在 m1 后，同样死循环。
2. **英文词条里的 ASCII 引号会打死整段 `<script>`**：`"this wave's mark + delay"`
   被替换进单引号字符串 → 语法错误 → `PLAN is not defined`、页面全空。
   `check_i18n` 只查「还有没有中文」，查不出这种。→ 已写进 `AGENTS.md §1 不许做的事`。
3. **中文注释里的 ASCII 双引号会被检查器当成 JS 字符串字面量**（`"…"`），
   逼你给注释写英文词条。注释里引用一律用 `「」`（改了 5 处）。
4. 视觉上被埋掉的两处，靠截图才发现：wave mark 的 `z-index:1` 被行背景盖住（改 3）；
   wave mark 徽标压在 w1 行的第一个 mark 上（新增独立「波」轨，`y` 起点 18px）。

## 验证
- 四档基线不变：**17.1 / 13.9 / 11.9 / 10.7 s**。
- headless Edge 功能测试：`T1=600 T2=3900 …`、加 mark、拖 mark 改延时、
  `tlMakeLink` 后起点横轴自动移到 `3900`、`plFillGaps` 写回 `gaps=[9,9,9,9]`。
- `check_i18n` 退出码 0；中英两版每个 `<script>` 块都能被 esprima 解析。

## 顺手修
- 快捷布置「选节奏型」后**波长串没自动填充**：`plFillGaps` 只改输入框显示值，
  没写回 `plan.rhythm.gaps`，随即被 `plRender()` 重画抹掉。
