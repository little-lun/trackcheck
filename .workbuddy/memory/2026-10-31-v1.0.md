## 验证
- `check_i18n` 604 条全绿；四档基线 **17.1 / 13.9 / 11.9 / 10.7**（未变）。
- **静默安装实测**：`setup.exe /S /D="D:\PVZ endless\_tmp_inst"` → exit 0，
  两个 exe 到位，注册表 `TrackCheck v1.0.0` / InstallLocation 正确，开始菜单 + 桌面快捷方式各 1 个。
- 装完的主程序双击 → 原生窗口标题「TrackCheck · PVZ 生存无尽研究工具」，
  本地服务 `HTTP/1.0 200 OK`、页面里能读到 `1.0.0`。
- **静默卸载实测**：`Uninstall.exe /S` → exit 0，目录清空、注册表条目 0、快捷方式 0。
- ★ 坑：`Start-Process -ArgumentList '/S','/D=D:\PVZ endless\x'` 会被 PowerShell 按空格拆开 →
  装到了 `D:\PVZ`。要写成 `/D="D:\PVZ endless\_tmp_inst"`（带引号的一整项）。
