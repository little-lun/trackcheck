## 一、阵型速查

```
      1列    2列    3列    4列    5列    6列    7  8  9
1路   冰∩    伞∩    双花∩  冰瓜∩  炮     炮前   ·  ·  ·
2路   曾∩    曾∩    伞∩    冰瓜∩  炮     炮前   ·  ·  ·
3路   炮     炮前   火炬∩  裂荚∩  炮     炮前   ·  ·  ·
4路   伞∩    曾∩    双花∩  冰瓜∩  炮     炮前   ·  ·  ·
5路   冰∩    曾∩    伞∩    冰瓜∩  炮     炮前   ·  ·  ·
```
**"炮前"不是空格**：炮占 **1×2**，第 5 列那门物理上占 5、6 两列；3-1 那门占 3-1、3-2。
**真正的空地只有 7、8、9 列。**

统计：炮 6（占 12 格）｜曾 4｜冰瓜 4｜双花 2｜伞 4｜存冰 2｜火炬 1｜裂荚 1｜南瓜 18（14 梯子）
造价：≈ **12000**（炮占 4950）

### RE 版四处不同（原因是矿工）

| 格 | 原版 | RE |
|---|---|---|
| 4-1 | 伞 | **曾**（多一道绞肉机打矿工） |
| 4-3 | 双花 | 伞 |
| 5-2 | 曾 | 伞 |
| 5-3 | 伞 | 双花 |

> RE 版矿工**出土眩晕更短**，原版在 3 路的拦截不够用 → 4-1 补曾，3 路后场变成 4 曾覆盖。
> 但**仍会啃 3-1/3-2 那门底线炮** → 选卡带炮套件 + 地刺。

## 二、节奏：**D5**（旧称 `ch5`）

```
26 版：D5        2021 版：ch5
轨道：PP | I-PP | I-PP   (6, 15, 15)
```

```
波1  PP     6s
波2  I-PP   15s
波3  I-PP   15s      循环 36s = 炮 CD 34.75
```

**万能轨道**：任何出怪都能无脑跑。
**但它亏**：一轮 2 冰（300 阳光）+ 冰透支（1/18s vs 产 1/25s），2 朵花一轮只产约 150。

### 松弛（压力小就放慢，把账扳平）【你】

```
允许松弛 ⇔ 没有：冰车、红眼、舞王、投篮
做法：快速僵尸跑到「第 8 列中心」时开炮
再慢可以：不冰（实测橄榄这类也能不下冰超慢松弛）
更慢可以：放跳跳、撑杆过去（撑杆翻越炮不啃，交后场曾收）
```

**投篮的特例 —— 忙里偷闲**
> 有投篮时不能完全松弛，但**只要 3 路没出投篮**，就能偷个闲
> （3 路那门底线炮没伞可罩，是唯一被投篮直接威胁的炮）。

### 7 列开发（好出怪时的"开源"）【你】

7 列是唯一空地，但**能临时用**：

| 级别 | 条件 | 做法 |
|---|---|---|
| **临时存冰** | 炮击能阻止推进 | 直接往 7 列放冰，**下一波刷新前预判点掉**（实际就是放下立刻点） |
| **经济区** | 快速僵尸里**没有 扶梯、小丑、撑杆** | 7 列摆 **1 个临时存冰 + 4 朵向日葵**，狠狠回复 |

> "临时"两层意思：① 这冰是**这一组出怪下**的位子；② 下一个 2F 不能松弛时，**它就是第一个被点的冰**。
> **这是全阵唯一能开源的地方** —— 后场 1~4 列全是存冰/曾/双花/伞，一格插不进去。

## 三、起手（前三波）【你】

```
开局数 4~5 秒 → 一对「预判炮」→ 落地炸死 w1
落地 → 立即再一对「预判炮」→ 炸死 w2
落地 → 立即点「预判冰」→ w3 一刷新就被冻住
冰车到 7~8 列交线 → 开炮炸 w3
```
**w2 的那对炮 = 轨道里的首个 PP**，之后顺 ch5 往下。

**两条铁律**
1. **I 和"快 PP"都要预判** —— 上一对炮落地就操作，不要等。
   > **预判是为舞王服务的**（预判炮顺带收矿工）。**没有舞王 → 直接退化成反应冰/反应炮。**
2. **落点 = 第 8、9 列交线**（怎么也得打到半个第 10 列）。
   > 2 炮 = 2 运算量 = 刷一波。只炸到 8 列以内 → 运算量不足 → **刷新节奏脱离预期**。
   > 第 10 列属场外（可伤条件：防御域左端 ≤ 800），靠落点前移吃那部分判定域。

**没预判成功** → 伴舞从 7 列钻出 → **落点退到 8 列**（放弃第 10 列）。

| 版本 | 舞王滑步 | 后果 |
|---|---|---|
| 原版 | 较长，伴舞出在 **6、7 列交线** | 已贴炮身，**窝瓜可能压不到** |
| RE 版 | 疑似较短 | 容错稍高，但**预判仍必要** |

> 术语：**「面瘫」= 预判冰 = 连打两个慢波 `I-PP | I-PP`**（2010 年原帖俚语）。

## 五、炮位为什么这么摆

| 威胁 | 结果 |
|---|---|
| 小鬼（落 3 列） | 往左走，**永不经过 5、6 列** → 安全 |
| 早爆丑 | 冻结后 9.5~12.6s 才炸，此时在 6~7 列 → 炸不到 5 列炮体 |
| **蹦极** | **机制上不可能把炮当目标**（偷炮只能靠栈位 bug） → 伞不用罩炮 |
| **伴舞** | ⚠️ **唯一天敌**。7 列召唤往左走，先撞 **6 列的炮前半身** |

> **炮占 2 格是双刃剑**：多吃 6 发落点，但也把"被伴舞碰到"的边界从 5 列前移到 6 列。

**3-3 火炬 + 3-4 裂荚**：小鬼落 3-3 啃火炬，3-4 裂荚**向后射**穿过火炬成火豌豆（40 伤害）—— 补上"后场 3 列"这个洞。

### 僵尸速查

| 僵尸 | 一句话 |
|---|---|
| 舞王 | **唯一天敌**（伴舞撞 6 列炮身）→ 预判冰；没预判则落点退 8 列 |
| 冰车 | 到 **7~8 列交线**发炮，炸点推前 |
| 红眼 | 4 炮一只；靠冰拖 + 集火 |
| **气球** | **完全按轨道跑，气球根本飞不出来，全被炸死**；漏了/松弛后才需要**三叶草** |
| 矿工 | 后场 4 曾；RE 版眩晕短，会啃 3-1/3-2 底线炮 |
| 撑杆 | **可以放过去**：翻越炮不啃，交后场曾 |
| 跳跳 | **可以放过去**：交后场曾 |
| 蹦极 | **偷不了炮**（机制上不选炮）；只偷后场植物 → 伞 + 冰杀 |
| 小丑 | 早爆丑炸不到炮；晚爆丑被 15s 冰波覆盖 |

## 六、开局：先发育 → 再布阵 → 最后搭梯

> 14 个梯子是本阵最大门槛。通用原理见 `docs/知识库/14-技术-搭梯与前期发育.md`。

### A · 0~2F：纯发育
```
选卡：花、蒜、伞、南瓜、南瓜(复制)、窝瓜、地雷、曾哥套件
① 1、3、5 路种满花（能不被啃到的地方全放花）
② 1、3、5 路的 8、9 列放蒜 → 把僵尸赶去 2、4 路
③ 3-7 放临时曾：收除铁桶外一切
④ 铁桶 → 地雷 / 窝瓜
交付：曾和伞全部就位｜南瓜除 1-4/3-4/5-4 外就位｜阳光 ≥ 4000
```

### B · 2~4F：布阵 + 前期生存
```
选卡：蒜、双子葵、炮套件、冰瓜套件、火炬、高坚果(按压力)、双向(有扶梯时)
① 底线炮(3-1) + 2/4 路前场炮
② 2/4 路冰瓜
③ 双子葵（发育期 1-1、5-1 也先放双子葵）
④ 1、3、5 路第 4 列放蒜并维护
⑤ 有扶梯 → 清空 1/3/5 路第 4 列蒜之前的所有植物，给扶梯让道
⑥ 3 炮 + 2 冰瓜 = 具备前期生存能力，开始搭梯
```

### C · 搭梯（通道 = 1/3/5 路）
```
1、5 路吃蒜后去向确定（各去 2 / 4 路）→ 先搭
3 路吃蒜后二选一 → 最后搭（减少浪费扶梯）

次序：
① 前场放蒜引导
② 2 或 4 路搭完 → 3-4 蒜换成「南瓜+双向」，准备搭 3 路
③ 2(4) 路搭完 → 铲 1-4(5-4) 蒜，准备搭本行
④ 1、5 路冰瓜最后搭：扶梯接近时快速下「西瓜→冰瓜」
```

> **为什么冰瓜最后**：格子被炸、或"刷新"（种植物/铲植物/种紫卡）都会让扶梯消失。
> **把要卡时机的那一步放到最后。**

### 风险与放弃
| 风险 | 对策 |
|---|---|
| 小丑 | "非常刺激"，技术不行就毁阵 → **放弃搭梯转压制** |
| 跳跳 | 带冰，合适时机点冰让底线曾收 |
| 冰车 | 带地刺；压力大可布**两路刚地刺** |

**收手**：前 10F 见不到扶梯 → 重开；20F 还没搭完 → 重开。

**三个坑**
1. 太早摆阵（不种花就没钱）
2. 不留通道（1-4/3-4/5-4 种了东西，扶梯进不来）
3. 顺序颠倒（先搭梯再补冰瓜 = 白费一次）

## 七、收尾：压血 + **故意留一路**【你】

```
① 炮把全场巨人压到「差 2 个 IO」（压力大压到「差 1 个 IO」）
   3 路会同时吃 2 路、4 路炮落点的双重伤害 → 直接暴毙
② 樱桃炸两路
③ 窝瓜压一路
④ 剩下一路：垫材拖住，不杀
```

**为什么要留一路**
```
ch5 一轮亏 150 阳光 + 2 冰
留一路拖 → 白字延迟（最多 49s）
→ 双花继续产阳光、冰继续冷却 → 把这一选卡的账补回来
```
> 压到"差 2 个 IO"而不是打死，就是因为**留的那个缺口是拖延的钩子**。
> 压力小时：剩 1 个 IO，**一个冰瓜就够收**，连垫材都省。

## 九、崩了怎么办

| 崩法 | 现场 | 事后 |
|---|---|---|
| 炮被冰车碾 | 灰烬清车 + 立即补炮 | 冰车该在 7~8 列就被炸 |
| 伴舞啃炮 | 炸点后移；漏了用暂停 | 改预判冰，让舞王原地召唤 |
| **RE 版底线炮被矿工磨** | 补炮；地刺/曾压矿工 | 选卡带炮套件 + 地刺 |
| 南瓜被啃穿 | 补南瓜 125 | 查梯子还在不在 |
| 存冰被偷/吃 | 补存冰 | 下一选卡少一张冰 → 全程松弛 |
| 冰不够 | 直接松弛：放慢、少冰、甚至不冰 | 这一选卡别硬打满 ch5 |
| 红眼推平 5 列 | 灰烬 + 垫材拖；炮集火 | 提高冰覆盖 |

## 十、每局检查清单

**选卡开始**
```
□ 6 门炮都在（第 5 列 ×5 + 3-1；注意 6 列是炮腿不是空格）
□ 2 个存冰（1-1、5-1）
□ 4 把伞没缺，双花在伞下
□ 3-3 火炬、3-4 裂荚还在
□ 梯子南瓜还在
□ 这一局要不要带三叶草（有气球）
□ RE 版：有矿工 → 炮套件 + 地刺
```

**起手**
```
□ 4~5 秒开预判炮
□ 落地立即再一对
□ 落地立即点预判冰
□ 落点贴近 9 列（有舞王无预判冰 → 退到 8 列）
```

**每波**
```
□ 有舞王？→ 预判冰（进场即冰）
□ 有冰车？→ 7~8 列交线发炮，炸点推前
□ 有红眼？→ 数只，炮排班
□ 伴舞漏了？→ 暂停键
□ 这四个（冰车/红眼/舞王/投篮）都不在？→ 可以松弛
```

**w9 / w19**
```
□ 红字后 7.2s 是下一波
□ 炮别打空，留给下一波
```

**w20**
```
□ 炮压血到差 2 个 IO（压力大差 1 个）
□ 樱桃炸两路、窝瓜压一路
□ 留一路拖，回经济回存冰
```
