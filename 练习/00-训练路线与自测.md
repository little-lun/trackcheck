# 00 · 训练路线与自测

> 目标不是"打过多少 f"，而是**建立可复用的判断力**：看到一个阵，能说出它该怎么打、为什么、什么时候会崩。

---

## 一、四阶段路线

### 阶段 1 · 术语关（1 周）

| 动作 | 验收标准 |
|---|---|
| 读 `01-基础`、`02-核心-刷新` | 能凭记忆画出"一次选卡时间轴" |
| 新读本第 1 篇 | 能说出 6s / 45s / 7.2s / 49s / 5s 各自对应什么 |
| 用布阵器画一个经典八炮 | 8 个炮位坐标全对，能指出哪些是危险区 |

**练习**：随便打开一个录像，只做一件事——在每次刷新时喊出"这是第几波、上波是什么组合"。

### 阶段 2 · 手动关（2 周）

| 目标 | 阵 | 数值 |
|---|---|---|
| 第一次过 100f | 传统八炮 / 经典八炮 | P4，9s 一对炮，落点 8 列偏左 |
| 学会预判 | 同上 | 舞王**开始指天**就发炮，不是等它召唤完 |
| 学会冰消珊瑚 | 十炮 | 红字后炮闪 5~8 下点冰 |
| 学会梯子南瓜 | 任何阵 | 后场南瓜主动搭梯，不再频繁修补 |

**训练法**：**只打一个节奏，打 20 次选卡**。每崩一次，记一句"崩在哪一列"。

### 阶段 3 · 节奏关（3~4 周）

| 目标 | 阵 | 节奏 |
|---|---|---|
| 提速 | 经典十炮 | P5，7.2s |
| 极限 | 经典十二炮 | P6，6s，落点 9 列，预判发炮 |
| 控丑 | 机械钟无炮 或 传统四炮 | 按曾列选控丑法 |
| 夜间 | 雾四炮 | S3（24,12） |

**验收**：能回答"为什么十炮是 7.2s 而不是 7s"、"为什么十二炮的落点是 9 列"。

### 阶段 4 · 研究关（长期）

| 目标 | 产出 |
|---|---|
| 独立算冰平衡 | 给定场地 + 节奏，算出需要几个存冰位 |
| 独立查波长表 | 给定压制需求，选出可行波长 |
| 独立验复用 | 用循环推论验一个不等距节奏需要几门炮 |
| 改造一个阵 | 把 ch6 改成 ch5，并说明代价 |

## 二、每次练习的 Checklist

```
□ 进场先看这波是什么组合（有没有巨人 → 慢速/快速/变速/极速）
□ 起手 6s 内是否已布好第一波应对
□ 加速波:上一波的减法是否在 4.4s 内生效（控丑）
□ 冰波:波长是否 ≤ 11.5s（防早爆丑）/ ≤ 20.3s（防晚爆丑）
□ w9/w19:清完后的红字处理是否卡准（7.2s 后下一波）
□ w19 之后:珊瑚/空降是否处理（冰 or 炮 or 灰烬）
□ w20:白字出现后 5s 结束，收尾有没有拖够 CD
□ 崩阵复盘:是"算错"还是"手抖"？算错记进知识库，手抖就再练
```

## 三、常见崩阵诊断表

| 症状 | 最可能原因 | 对症 |
|---|---|---|
| 前置炮被啃 | 反应冰，伴舞已走出 | 改**预判冰**，让舞王原地召唤 |
| 水路炮被啃 | 海豚已跳过 | 预判冰冻在岸上；或 9 列高坚果（但海豚能跳过 9 列！） |
| 后场南瓜反复修补 | 小鬼啃 | **梯子南瓜** |
| 水路炮被珊瑚啃 | 冰消珊瑚时机错 | 炮闪 5~8 下点冰；或炮闪 8 下发炮 |
| 节奏越来越快、脱离控制 | 自然输出意外刷新 | 挖掉 8、9 列植物（3C 八炮的标准解法） |
| 小丑炸了一片 | 没控丑 / 控丑不严谨 | 按曾列选控丑定式；8 列曾**必须**加 5 列喷 |
| 冰不够用 | 冰透支 | 加存冰位（ch4 要 3 个）；或加首代/代奏 |
| 炮不够用 | 复用不成立 | 用循环推论验最短间隔；加炮或拉长波长 |
| 红眼砸炮 | 压制强度不足 | 提高参数；或加垫材；或改节奏 |
| 气球落在炮上 | 用猫了 | **前置炮加猫，气球笑弯腰** —— 改三叶 |

## 四、自测题（答案在文末）

**A 组 · 基础**
1. 一次选卡有几波僵尸？几个旗帜？w9 结束后跳什么字，几秒后刷下一波？
2. "3 路 5 列"和"5 列 3 路"是同一个位置吗？为什么？
3. 六行场地的"岸路"是哪两路？"陆路"包含水路吗？
4. 寒冰菇冻结水面多少秒？这 3 秒能挡住什么？

**B 组 · 运算量**
5. 一个核弹的运算量是多少？在边路呢？
6. "2 个运算量 = 刷一波僵尸"。那么一次覆盖 3 行的炮击，会刷吗？
7. 为什么 ch6 的参数是 6，而不是"4 波"？
8. 基础运算量和附加运算量的区别是什么？超多炮的本质是什么？

**C 组 · 节奏**
9. ch6 的 `36 = 6 + 12 + 6 + 12` 是怎么来的？
10. 为什么 P 类节奏的循环是 36s？精确值是多少？
11. ch4 / ch5 / ch6 分别需要几个存冰位？
12. S4 为什么用 20s 冰波 + 7.5s 加速波？这两个数各防什么？
13. 冰波平均波长 17.8s 意味着什么？

**D 组 · 数据**
14. 玉米炮从释放到爆炸多少 cs？CD 多少 cs？
15. 白昼点冰（咖啡豆唤醒）到生效大约多少 cs？夜间呢？
16. 小丑开盒到爆炸多少秒？早爆型/晚爆型各占多少？
17. 僵尸进家条件：普通僵尸 / 巨人 / 橄榄分别是多少？
18. 忧郁菇的四发命中延迟是多少？

**E 组 · 判断**
19. 一个阵在 8 列有曾哥。想严谨控丑，最晚什么时候让冰生效？还需要加什么？
20. 加速波想防投篮，波长上限是多少？冰波呢？
21. 为什么"经典八炮"被认为是场地与输出的完美平衡？
22. 24 炮的"精准之舞"为什么说有效时间只有一帧？

## 五、答案

1. 20 波，2 个旗帜；红字，7.2s。
2. 不是。坐标写作"路-列"，路是横向行、列是纵向列，顺序不可换（虽然口语常混，正式记录要统一）。
3. 2、5 路；不包含（陆路 = 1、2、5、6）。
4. 3.0s（300cs）；挡珊瑚三人组、挡空降三人组（冻结天空）。
5. 2；若在边路只算 1（覆盖不到 4 行）。
6. 不一定。1 个运算量"很危险"，多数会刷，但取决于该波血量与组合；覆盖 ≥4 行才是必然。
7. 因为 `参数 = 加速波数 + 减速波数×2`。ch6 = 2 加速 + 2 减速 = 2 + 4 = 6。参数记录的是**有效操作时机数**，不是波数。
8. 基础 = 目的为激活刷新的加法；附加 = 目的为保护阵型的加法。超多炮 = **附加运算量远超基础运算量的波动轨道**。
9. 加速波 6s ×2 + 减速波 12s ×2，且 `2 + 2×2 = 6` 满足参数定义。
10. 因为炮 CD = 3475cs ≈ 34.75s，取整 36s 便于 6 等分。精确最快可取 **34.75s**。
11. C6i/ch4 → 3 个；ch5 → 2 个；ch6 → 1 个。
12. 20s 冰波防**晚爆丑**（13.2 + 4.0 + 1.1 ≈ 18.3，≤20.3 安全）；7.5s 加速波配合前置冰波防小丑，同时也控制在投篮软波长附近。20 + 7.5×2 = 35 ≈ 36，CD 刚好。
13. 耗冰量与产冰量正好平衡（都是 19 个冰）。**≥17.8s 必然平衡，<17.8s 必然透支。**
14. 378cs（非屋顶水路）/ 373~376（非屋顶陆路）；CD 3475cs。
15. 约 298~299cs；夜间 100cs。
16. 1.10s；早爆 5%、晚爆 95%。
17. 普通 −100；巨人 −150；橄榄 −175。
18. 74、102、130、158 cs。
19. 刷新后 **4.4s 内**；且必须在 **5 列至少加一个喷**，否则视为控丑不严谨。
20. 加速波 **7.46s**；冰波 **19.29s**。
21. 8 炮只为刷新服务，没有任何"为放更多炮而做的保护操作"，也没有"为制造缓冲空间而产生的附加操作"——场地与输出达到平衡点。
22. 因为 P 必须在刷新前 15cs、D 延迟 105~110cs，两个窗口只在一帧内同时成立；早了漏伴舞，晚了漏小鬼。

## 七、进阶自测（理论层 08~10 · 工程层 11~12）

> 这一组不问"怎么打"，问"为什么"。答不上来说明还在抄阵。

**1.** C 系节奏的参数怎么算？和 P 系有什么不同？
**2.** `ch6` 默认指"对 ch6"还是"邻 ch6"？两者的轨道长什么样？
**3.** `ch7` / `ch8` / `ch9` 在现行体系里还算独立节奏吗？
**4.** `Cxu` 里的 `u` 是什么意思？
**5.** `I6i` 的参数 6 是怎么定出来的？
**6.** 一个阵打到 `0` 波时，出怪算法在哪些方面还没到满强度？
**7.** 为什么前 4 波不可能出小丑和冰车？前 14 波不可能出红眼？
**8.** "变速"的物理成因是什么？
**9.** 某一行刚丢了小推车，接下来两波该行压力会怎样？为什么？
**10.** IO 等级 = 3 是什么意思？
**11.** 无炮的"冰垫炸补"里，灰烬伤害是多少？为什么这个数字重要？
**12.** 2 列曾控丑的窗口是多少 cs？6 列曾呢？
**13.** 海豚"概率跳过 9 列高坚果"这个说法错在哪？
**14.** 为什么"车底垫"消砸率不被接受？哪三种植物是例外？
**15.** 拦截炮在哪个 cs 会出 bug？为什么？
**16.** ICE3 为什么"时灵时不灵"？
**17.** 读 `[[[6A9EC0]+768]+559C]` 得到的是什么？有什么用？
**18.** 想验证某一波的真实刷新阈值，读哪两个字段？

---

### 答案

1. C 系用**过怪量**（一循环过了几波）；其它系用 **加速波×1 + 减速波×2**。C 系只针对无炮，套炮阵口径会自相矛盾。
2. **默认"对 ch6"**。对：`I-P|P|I-P|P`（减加|减加，可拆成两个等长子片段）；邻：`I-P|I-P|P|P`（减减|加加）。
3. `ch7` 并入**邻 C7u**；`ch9` **仍独立**（C9u）；`ch8` 是拖太长的**邻 C8u**（实用意义不大，一般可压回普通邻 C8u）。
4. **没有意思。** 它是分类名 `Cxu` 的一部分，不是后缀。历史来源是 u 原表"变奏"（Cxu = 卡阵变奏）。
5. 1362 × 3 = 4086 比 1362 × 2 = 2724 **更接近 3475** → 取 6。规则：以最接近 3475 的循环节数量定参数。
6. 四个饱和阈值：**47f**（阶数失效）、**85f**（级别上限统计失效）、**109f**（红眼上限失效）、**126f**（级别上限严格失效）。
7. **阶数**：三阶（含小丑/冰车）从 **w10** 起；四阶（含白眼/红眼）从 **w15** 起。
8. **红眼数量上限**：累计红眼达上限后，**非旗帜波不再出红眼**（上限初始 0，轮数 5 起每轮 +1，54 起固定 50）。
9. **大幅下降**。`MowerTest ≤ 1 → Weight 0.01`，`1 < MowerTest ≤ 2 → Weight 0.50`。
10. 红眼吃 **1 次**灰烬后就能被自然输出打死（因为 IO 等级 = 4 − 灰烬次数）。
11. **1800**。因为除红眼（6000）外几乎所有僵尸一击必杀 —— 这就是"炸"能替代一门炮的根据。
12. 2 列曾是 **1081cs（10.81s）内且不恢复原速**；6 列曾是刷新后 **8.88s** 生效（配岸路 2 列曾则 8.88~10.81s）。
13. 栈位关系是**确定性**的：满足条件 100% 跳过，不满足 0%。所谓概率只是人为操作让序号时大时小。
14. 僵尸栈位在正常游戏中**不可控**，判定从栈位最小的僵尸开始，结果不可复现。例外：**地刺、窝瓜、三叶草**（免疫碾压，且地刺种后 26cs 才扎车）。
15. **激活后 106cs**（减速 211cs）。小鬼栈位低于巨人时，该 cs 内小鬼存在时间 0cs、坐标未初始化（内存垃圾值），下一 cs 才传送 → 概率拦截失败（表现为炸黑巨人却没炸掉小鬼）。
16. 咖啡豆与寒冰菇的**序号相对大小**不同，会让总生效倒计时差 **1cs**（199 vs 198）。
17. **下一波僵尸倒计时**（cs）。这是预判炸 / 预判冰最该锚定的物理时钟，`Prejudge/Until` 本质就是在读它。
18. `5594`（达到刷新条件的血量）÷ `5598`（本波总血量）= 本波实际阈值（0.5~0.65 的那个随机数）。
