## 二、选卡：三种配置【稿】

| 出怪 | 配卡 | 说明 |
|---|---|---|
| **中速及更慢** | 冰、冰（复制）、咖啡豆、南瓜、窝瓜、**辣椒/樱桃/核弹**、**小喷/花盆** | 标准 10 张，两垫材撑红眼 |
| **快速** | 同上，但**复制南瓜** 替掉 **复制冰** | 冰够用，南瓜磨损快 |
| **极速** | **不带垫材、不带窝瓜**；带**曾哥套件（睡莲 + 大喷 + 曾哥）**；**若无车则带大蒜** | 追不上操作，改结构 |

**永远不带三叶草** —— 46 交错双猫已经够防空。

### 单次成本（心里有个数）
| 操作 | 成本 | 操作 | 成本 |

## 三、三档流程（照着走）

### 慢速关 → `C4io: N | AA' | I | I`

**四个操作全是控丑动作**，不是"输出 + 控丑"混合：

```
波1  N    灰烬控丑   （2 运算量，清场）
波2  AA'  灰烬控丑   （樱桃打上半场，辣椒固定 5 路）
波3  I    早冰控丑 + 拖时间
波4  I    早冰控丑 + 拖时间
```

**顺序为什么是 N → AA' → I 而不是 N → I**：
核和冰共用咖啡豆。N 用完咖啡豆后直接接 I，**CD 来不及**；
中间插一个纯卡片的 AA'，正好把咖啡豆 CD 让出来。
> 这条轨道的顺序是**咖啡豆 CD 决定的**，不是伤害节奏决定的。

### 快速关 → 逐波控丑，AA' 拆开

```
每波刷新 →
  有小丑？
    有 → 灰烬（辣椒/樱桃，都在 5 路）或 早冰
    无 → 交给 IO

【固定动作】w9 → w10 的长间隔（约 52s）：
    在 2-7 补一个【大喷菇】
    理由：上 f 严谨控丑（冰多花点没关系）→ 下 f 2 路放羊（冰省下来）
          这个大喷就是给下半场提前买好的丑抗保险
```

**辣椒的第二个用途**：不带窝瓜时，辣椒还要**烧掉冰道**，腾出 `5-7` 核位 / 5 路临时樱桃位。
→ 所以辣椒必须单独占一波，不能和樱桃捆在一起。

**关键**：放弃 2 路的严谨控丑，卡全给 5 路。

### 极速关 → 几乎不操作，靠结构

```
无冰车、无投篮车 → 大蒜驱逐 2、5 路小丑（2-9 / 5-9）
有冰车或投篮车   → 2-7、5-7 放大喷，抬高丑抗
         【选卡】车会把大蒜连格子一起碾掉 → 这一档**不带大蒜**（也不必把核补回来）
         【时机】开场尽快放满（极速关本来就没别的事干）
         【5-7 被车压】→ 先用灰烬清车开格，再补大喷
                        （IO 不够 → 车压不掉 → 直接种下去就被压，白花 75）
                        → 被压就补，不额外操作；结构位大喷本来就是消耗品
摆完就不管，剩下交给 IO
```

> 极速关的核心不是手速，是**结构**：冰追不上刷新时（咖啡豆 CD 被超过），只能靠改道/加丑抗。

## 四、核坑使用表

| 位置 | 优先级 | 何时用 | 注意 |
|---|---|---|---|
| `2-7` / `5-7` | **主力** | 常规反应核 | **必须延迟**（见下） |
| `2-9` / `5-9` | 一次性 | **仅 w1 / w11** | w11 前要在 **w10 用窝瓜压 2/5 路冰车**，防 9 列被冰道盖 |
| `2-8` | 备用 | 樱桃没在冷却时 | 与樱桃位抢 |
| `5-8` | 备用 | 同上 | **长期被冰道覆盖**，能用的机会少 |
| `3-8` / `3-9` | 应急 | **2 路被小丑炸后** | 临时坑 |

### 为什么 7 列核要延迟【推】

核的判定是 **圆心 (x+40, y+40)、半径 250** 的圆。
`2-7` 圆心 = (560, 205)，**同一个核对不同行的水平触达距离差别极大**：

| 目标行 | 水平触达 | 最远 x |
|---|---|---|
| 1 路 | 196 | **756** |
| 2 路（本行） | 240 | 800 |
| 3 路 | 249 | 809 |
| 4 路（对岸） | 229 | **789** |
| 5 路 | 168 | 728 |

僵尸出生点 **x = 780~819** → **刚出生的僵尸还在圆外**。
**所以：本行几乎可立即，4 路等半秒，1 路要等约 2 秒再点。**
`2-9` 圆心 x = 760，本行触达 1000，**盖得住出生点，所以不用挑时机**。

> 实操记法：**7 列核"慢半拍"，9 列核"见刷新就点"。**

## 五、冰的分配（本阵最重要的一条）

```
一个冰，三个候选用途，只能选一个：

  冰消珊瑚    → 只保住南瓜          （可逆，补南瓜 125 阳光）
  冰杀蹦极    → 保住一株植物        （不可逆，植物直接没了）
  控丑 w10/20 → 防曾哥被炸          （不可逆）

本阵选择：冰杀蹦极（同时兼职 w10/w20 控丑）→ 一份冰两个收益
珊瑚：不处理，任其啃南瓜
```

### 冰杀蹦极怎么打【稿】
1. 蹦极的**标靶一落地**就可以开始准备；
2. 在「靶子落地」到「蹦极可见」之间**点咖啡豆**（唤醒存冰）；
3. 冰约 **2.98s 后生效**，正好覆盖蹦极**停留期（3.0s）**；
4. 冻结期间 **2 个忧郁菇**把蹦极打死 → 偷不到。

> 判定依据：`05` 的数据里，双曾冰杀且被抓一曾的极端情况被偷率约**十亿分之 4.7**，可忽略。

## 七、开局：先发育，再布阵，最后搭梯

> **纠正**：以前我把开局写成"直接按顺序摆阵"，那是错的。
> **所有阵（包括本阵）前期都是"满屏种花"起步，布阵时有计划地铲花。**
> 通用原理见 `知识库/14-技术-搭梯与前期发育.md`。

### 阶段 A：纯发育
```
① 能种的地方全种花（水上先铺荷叶 → 花）
② 1~2 个临时输出点：放在能收杂的位置（收除铁桶外的一切）
③ 铁桶 → 窝瓜 / 地雷
④ 用蒜把僵尸往别路赶，保护种花区
```
**目标：经济起来 + 阵里的伞、曾就位 + 阳光攒够。**

### 阶段 B：布阵（边布边铲花）
```
① 水上铺荷叶 16 张
② 水路 6~9 列：忧郁菇 + 南瓜（骨架先立）
③ 2 路：瓜(1)、伞(2)、瓜(3)、瓜(4)、曾(5)、曾(6)
④ 边路：1路 曾-曾-瓜-喷-喷；6路 瓜-曾-瓜-喷-喷
⑤ 5 路：伞(1)、曾(2)、冰(3)、瓜(4)、曾(5)、曾(6)
⑥ 香蒲：3-4 裸放、4-6 套南瓜
⑦ 最后补 6 朵双子花（花是最后才升级的，前期先用普通花顶）
```
> **每布一格，就铲掉一格的花** —— 花是脚手架，阵是建筑。

### 阶段 C：搭梯（只有 4 个，很简单）
```
⑧ 1-2 / 1-3 / 2-2 / 2-3 换成模仿者南瓜
⑨ 5 路全程不搭梯
```
> PE 是后院，1、2 和 5、6 都是陆路，扶梯去向清楚 → **比前院好搭得多**。
> 只有 4 个梯子，是本库里最轻松的搭梯任务。

**四个坑**
1. **5 路别搭梯**（辣椒要烧梯，辣椒路必须无梯）
2. 别让冰道盖住 **2-8**（樱桃位）—— 2 路杀车快，一般能保住；5-8 保不住是正常的
3. 梯子南瓜用**模仿者南瓜**（约定 + 便于交流）
4. **先花后曾**，否则经济锁死

## 十一、收尾速查（w9 / w19 / w20）

> **轨道结束 ≠ 战斗结束。收尾是独立环节，必须预先设计。**

### w9 / w19（中场）→ 目标：拖住 + 减损

```
① 1、6 路都有红眼？
   → 在红眼被 5 列曾攻击时点冰（挑火力最大那一刻，让减速额度花在高 DPS 段）
   → 只拖一时，压不死
   → 有窝瓜 → 搞死其中一路
   → 剩下一路 → 进 ②

② 只剩一路红眼？
   → 一直下垫材（减速巨人的举锤时间 ×2，两个垫材就能控死，永远不前进）
   → 停下 = 一直在曾的射程里掉血
```

### w20（真收尾）→ 目标：补齐 IO

| 路 | IO | 补法 |
|---|---|---|
| 2 路 | 4 ✔ | 不用管 |
| **5、6 路** | 3+ / 2+ ✘ | **冰生效时，在 `6-9` 下樱桃**（一颗通吃两路末段） |
| **1 路** | 2+ ✘ | **窝瓜，但要"稍后"用** |
| 1、6 收尾 | 差一丢丢 | **一个垫材 → 红眼举锤即死** |

**樱桃为什么必须等"冰生效那一刻"**：
```
早 → 巨人还在第 10 列（场外），只有部分判定域进场 → 炸不完整
晚 → 冰车把冰道推到 9 列 → 种不下去
刚好 → 巨人全部走到最远、判定域完整在场内，冰道又还没铺到 9 列
```
> 第 9 列樱桃**其实已经能炸到第 10 列的巨人**（不是"够不到"），
> 早炸的问题是**打不完整**：场外那截不吃场内伤害（可伤条件：防御域左端 ≤ 800）。
顺带：w20 用完樱桃，到下一 2F 的 `AA'`（w2）时 CD（50s）早已转好，不占额度。

**1 路窝瓜为什么不能出场就用**：
```
窝瓜"进范围就触发"，落点 = 触发那一刻的目标
w20 里冰车/小丑/扶梯/橄榄都更快 → 先到，把窝瓜骗走，红眼毫发无伤
→ 必须等快速僵尸过去、红眼成为最前面的那个
```

**红眼有快有慢怎么办**：用垫材**钉住走得快的**，等慢的追上来，让它们重合，一发窝瓜压完。
> 垫材在这里当"胶水"用，不是挡路。

**"举锤即死"是什么**：红眼没死不是输出不够，是它**还在走**、走出了射程。
放个垫材让它**停下来**，剩下的血自然被收掉。
> 垫材的三个职能别混：**垫红眼（留人）/ 控死减速巨人（钉住）/ 聚拢快慢不一（当胶水）**。
