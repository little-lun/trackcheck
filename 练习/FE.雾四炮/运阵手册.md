```
4路    荷+炮   荷(炮身) 荷+炮    荷(炮身) 荷+曾∩   荷+曾∩    ·  ·  ·
5路    双花∩   曾∩模    冰瓜∩模  大喷∩   大喷      ·        ·  ·  ·
6路    曾∩     伞∩模    冰瓜∩模  大喷∩   大喷      ·        ·  ·  ·
```
**炮占 1×2**：`(3,1)` 占 3-1、3-2；`(3,3)` 占 3-3、3-4。**水路 1~4 列是满的。**

统计：炮 4｜曾 8｜大喷 8｜冰瓜 4｜双花 2｜伞 2｜荷叶 12｜南瓜 20（8 个梯子）
造价：≈ **12650**

### 现代常用改（只动两格）

| 格 | 原阵 | 改 |
|---|---|---|
| **3-5** | 荷+曾+南瓜 | **荷+空南瓜**（= **点冰格**） |
| **4-5** | 荷+曾+南瓜 | **荷+双花+南瓜** |

→ 曾 **8→6**，双花 **2→3**。目的：**纯经济**（省 700 造阵费 + 日常收入 +50%）。

> **3-5 的空南瓜不是废格，是"点冰格"**【你】：
> 模仿者冰放陆路，变身 320cs 那一刻可能被红眼一锤砸掉；放水上套南瓜 → 绝对安全。
> 还可以换成 **花 / 猫 / 曾**。**放猫之后部分节奏可以不带三叶草**（本阵陆路没有前置炮，不犯"前置炮加猫"的忌）。
>
> ⚠️ 拆曾的代价有两条：
> ① 水路的蹦极冗余从 4 曾降到 2 曾（仍满足定式，只是零冗余）→ §六
> ② 岸路（2、5 路）的 4~6 列失去曾支援 → **车抗不足** → 所以 **S3 必须用原阵**

### 怎么选【你】
```
标准答案 → S3（36s，4 炮一轮刚好用完）
          原阵跑 S3 正好：经济压力最小 + 岸路有车抗
          其余三个解都亏经济，是为了别的目的（爆发/控场/变奏）
```

**S3 的两条硬约束【你】**
```
① 必须用原阵（8 曾）
   3-5 / 4-5 那两个曾能打到 2 路 / 5 路的 4~6 列
   拆了 → 岸路车抗不足 → 冰车推平
② 24s 慢波很难
   冰车【维】不受冰冻减速、不被南瓜阻挡 → 冰压不住它，只能等炮
   → 边路 5 列大喷几乎必死（冰车 2226cs 就能碾到）
   → 但 4 列大喷反而不会死（差一格，超出 24s 窗口）
```
> 所以 S3 的"稳"，是**用 8 个曾换来的**，不是白给的。

**经济账**（为什么只有 S3 不亏）：

| 解 | 循环 | 每循环消耗（**夜场价**） | 折合 | 亏/平 |
|---|---|---|---|---|
| **S3** | 36s | 1 冰 **75** | 2.08/s | **平** ← 原阵正好卡在这 |
| **N6s** | 54s | 2 冰 **150** | 2.78/s | 亏，实测 **≈900/选卡**【你】 |
| **P3-n** | 36s | 1 核 **125** | 3.47/s | 亏，但**和 N6s 差不多**【你】 |
| **C4io** | 50s | 1 冰 + 1 核 **200** | 4.00/s | 亏最多（未实测） |

> **价格口径**：FE 是**夜场**，冰 = 寒冰菇 **75**、核 = 毁灭菇 **125**，都不用咖啡豆。
> （旧版写的 150 / 200 是**白天口径**：冰 75 + 咖啡豆 75；毁灭菇 125 + 咖啡豆 75。已改。）
>
> **为什么 P3-n 单价更贵、总账却和 N6s 打平**：
> 核 3.47/s > 冰 2.78/s，但 **P3-n 波长短（12s）→ 僵尸走得浅 → 补南瓜少**。
> 两笔正好抵消 —— 这就是你说的"亏的经济差不多"。

> **所有现行阵改都在解决经济问题** —— 因为除 S3 外全亏。

### N6s 实战实测【你】
```
操作：惬意、简单，全部反应操作，不用预判（波长长，刷新后还有时间）
经济：三花改仍亏 900+/选卡（只有正常按轨道 + 补南瓜，无额外损耗）
结论：关卡有紧有松 + 本阵不怕投篮 → 松弛机会更多 → 跑 N6s 冲关可行
```
> **亏是"单看账"的亏，靠松弛关补回来。** 跟无炮"收尾留一路拖回本"是同一思路。

### P3-n 实战实测【你】（2026-10-18）

```
手感：也不错，比 N6s 紧一点，但能跑
经济：亏损和 N6s 差不多（见上表）
问题：节奏一松就被"砸大喷"——标准节奏下应该不会
```

**P3-n 为什么比 N6s 脆**：
```
冰 = 止血（冻住 → 阵线不后退，误差清零）
炮/核 = 治疗（掉血 → 但僵尸还在走）

N6s 有 2 张冰 → 每 54s 有两次"把阵线推回去"的机会
P3-n 有 0 张冰 → 全靠炮的节奏，**晚一次就永久落后**
```

**四条实操要点**：
```
① 炮：刷新就发，不等僵尸走位（释放→爆炸 378cs，落点自然在 8~9 列）
② 红线 16.65s（1665cs，巨人走位开始飘）→ 12s 的波余量只有 4.65s
③ 核 CD 50s > 循环 36s → **必须带双核：核 + 模仿者核**（0s 核、36s 模仿核、72s 核）
   而 N6s 要"模仿者冰" → 两张模仿者卡位冲突，**两个解不能共用一套选卡**
④ 双核 → **要两个核坑位**：毁灭菇原地留坑（时长⚠️待核），同格不能连放
   陆路 7~9 列是灰烬位，占了就腾不出手 → **水路第 7 列**（一张荷叶 25）当第二坑位
   代价：7 列被钉死 → 不能垫荷叶引海豚、不能放灰烬
```
> **5 列大喷无南瓜、无曾支援**（§6.1）→ 巨人一到 5 列必掉。
> 所以"被砸大喷"不是运气，是阵线退了整整一格的信号。
> **5 列大喷无南瓜、无曾支援**（§6.1）→ 巨人一到 5 列必掉。
> 所以"被砸大喷"不是运气，是阵线退了整整一格的信号。

### 原帖要点（2010，作者口述）【帖】

```
① 冰不用挑位置 —— 小丑有自然抗性，所以「一出来就冰」效果最好
② 冰 CD（50s）跟不上春哥 CD（34.75s）→「冰两次就放一次核」，或让炮提前发射
③ 小丑唯一战果：炸 6 列曾的南瓜 / 炸放核弹的荷叶（都能补）
④ 核弹要在小丑爆之前放，就不会被炸掉
⑤ 阳光不够 → 1、6 路大喷换花（⚠️ 见下"争议"）
⑥ 节奏固定 → 全屏盲炸也能打
```

> ⚠️ **第 ⑤ 条有争议**【你】：边路大喷经常是**消耗品**，跑较慢的节奏容易死，**尤其 S3**。
> 所以这个补丁在快节奏下划算，在慢节奏下反亏。现代改转向"拆水上曾"就是这个原因。

| 卡 | 用途 |
|---|---|
| **冰 + 复制冰** | 减速波 / 拖时间（**N6s 必需**：54s 里两张冰，冰 CD 50s） |

## 五、FE 的三个特殊性

```
① 没有天降阳光 → 2~3 双花是唯一收入
② 有雾，本阵主张「不开雾盲打」→ 靠记忆+声音+轨道，不能临场发挥
③ w20 后珊瑚从水路 6~9 列钻出
```

**珊瑚：不用管**【你】
> 只出现在水路 6~9 列；7~9 列是空的，它得走过来，
> 路上要么被炮顺手炸掉，要么被 6 列那对曾慢慢喷死。就算啃到南瓜也只是磨损。

**这也揭示了本阵的设计哲学**：
> **"这个阵只关心僵尸推进的阵线（速度），具体的僵尸都没什么意义。"**
> 速度压住了，什么僵尸都无所谓 → 所以才能「自然抗爆」，才能「盲打」。

### 【拆曾的代价】水路南瓜压力大 → **冰要晚放**【你】

```
拆了 3-5/4-5 的曾 → 水路 5~6 列只剩一对曾
→ 海豚游到 5 列一带逗留时间变长 → 南瓜挨啃
→ 慢波（I-P）里：让海豚先游进 6 列曾的射程，**再**冻住
→ 冻在射程里 → 曾收得掉 → 南瓜少挨啃
```

> **为什么敢晚放？** 因为小丑不用控（有自然抗性），
> **冰的时机是自由的** —— 才能拿去服务海豚，而不是被控丑绑架。

### 6.3 两个必背

**投篮 —— "砸了也白砸"**
```
底线 = 1、2 列【维 07】
陆路底线上的 曾/伞/花 全在 1-2、6-2 两把伞里
水路 1~6 列是「安全炮位」，炮不归投篮管
→ 投篮没有可砸的贵东西 = 不怕它 = 松弛的开关从 4 个变 3 个
```
> S3 的冰波 **24s ≫ 19.29s 红线** → 这个阵**根本压不住投篮**，全靠伞。

**蹦极 —— 没有偷盲**（定义：伞没罩到 **且冰杀也不成立** 的格子）

```
偷盲 = 「不能冰杀」的格子，不是「伞没罩到」的格子
能冰杀的格子 = 有防御 → 不算偷盲
```

**两条定式**【维 入门·蹦极】
```
① 两曾
② 一曾 + 一瓜 + 任意其他输出（大喷菇也算）
```
- 伞下 12 格（四路 1~3 列）→ **伞免疫**
- 水路 4~6 列 → **2~5 曾**，走定式①
- 2 路 / 5 路 4、5 列 → **2~3 曾**，走定式①
- 1 路 / 6 路 4 列 → **1 曾 + 冰瓜**，走定式②
- `1-5` / `6-5` → **0 曾**（只有冰瓜 + 大喷）⚠️ 但被偷只亏 75 = 冰钱，**本来就不该冰**
- 改版后：3-6/4-6 = 2 曾（零冗余）、4-5 花 = 1 曾 + 瓜 → **仍全部满足定式**

**冰不冰，先算账**
```
1 个大喷被锁 → 不冰（75 换 75，白忙）
≥2 个大喷被锁 → 冰（75 换 150+）
花 / 曾被锁 → 必须冰（200 / 225，且失位连锁）
```

### 6.4 前场垫荷叶：把海豚磨损摊到 4 个南瓜【你】

```
改版拆了 3-5 曾 → 海豚都挤到 5~6 列啃，实际只有 2 个南瓜在挨
解法：水路 7~9 列垫 1~2 张空荷叶
     海豚遇水上植物会提前跳（"跳后的减速海豚在双曾火力下走不了一格"）
     → 提前落进 6 列双曾射程 → 磨损摊到 4 个南瓜
成本 25/张，收益是南瓜补种砍半（125/个）
```
> ⚠️ 具体垫第几列、几张、会不会挡灰烬位，待你定一个顺手的排法。
> **和水路 7 列核坑位冲突**：P3-n 双核要占 7 列当坑位，那一格就垫不了荷叶 → 两者二选一。

### 6.5 陆路 4 列大喷搭梯（8 → 12 个梯子）【你】

**前提**：水路 7 列不做核坑位（不跑 P3-n 双核，或坑位另有安排）。

```
5 列大喷是冰车挡板，必死 → 它死后僵尸直接啃 4 列南瓜
→ 1-4、2-4、5-4、6-4 是全阵磨得最快的南瓜
→ 这 4 格搭梯 → 僵尸爬过去不啃 → 补南瓜再砍一截
```
**代价**：
```
① 布阵期多引 4 次梯子僵尸，而且梯子会先架在"遇到的第一个植物"上
   → 要先不放 5 列大喷，等梯子走过头，再补 5 列
② 这 4 格在伞外 → 南瓜被蹦极偷 = 南瓜和梯子一起没
③ 梯子只防"啃"，不防"碾"：冰车照样把 4 列碾掉
```
> 一句话：**前场垫荷叶省"海豚那部分"，4 列搭梯省"5 列死掉之后那部分"。**

## 九、每局检查清单

**选卡开始**
```
□ 4 门炮都在（水路 1~4 列，占 8 格）
□ 曾数对（原阵 8 / 改 6）
□ 2 把伞、双花都在伞下
□ 前场荷叶垫了吗（7~9 列，1~2 张，引海豚提前跳）
□ 梯子还在
□ 三叶草：有猫 / 手上冰多 → 可以不带
```

**每波**
```
□ 有小丑？→ 不用特意控（6 列曾 = 早爆炸不到、晚爆喷杀），一出来就冰
□ 有红眼？→ 数只，按 3 炸/只算（不是 4 炮/只）
□ 有冰车？→ 冰没用（不受减速）；靠大喷 + 相邻路曾
□ 有海豚？→ 拆曾的阵：慢波里让它进曾射程再冻（冰晚放）
□ 水路 5、6 列曾有南瓜吗
```

**旗帜波（w10 / w20）**
```
□ 蹦极落在谁头上？
     花 / 曾 → 必须冰
     ≥2 个大喷 → 冰（划算）
     1 个大喷 → 放它偷，省冰
□ 冰留着 —— 蹦极只在这两波出
```

**w9 / w19**
```
□ 炮别打空，留给下一波
□ 红眼多就先冰拖
```

**w20**
```
□ 冰点了吗（刷新瞬间，别等）
□ 点完冰立刻 4 炮齐发 —— 别等 PP 的时点
□ 红眼 ≥3 只 → 上核
□ 珊瑚不用管（水路 6~9 列，自己走进来送）
```
