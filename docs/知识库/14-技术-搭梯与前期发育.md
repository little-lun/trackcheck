# 14 · 技术：搭梯与前期发育

> 这是**跨阵型的通用技术**，不是某一个阵的附庸。
> 来源：`【你】`你的实战说明（以 DE.双冰六炮 14 梯为例）；`【推】`我的推演；`【维】`维基。
> 实例阵：`练习/DE.双冰六炮/`、`练习/PE.电波钟无炮/`

---

## 一、搭梯是什么，为什么要搭

**梯子南瓜** = 让梯子僵尸（扶梯）把梯子架到南瓜上。
南瓜一旦有梯，僵尸会**架梯翻越而不是啃食** → **南瓜永久免维护**。

`06` 里那条"磨损表"的背面就是它：
> 扶梯对本阵**零磨损**，正因为后场全是梯子南瓜 —— 它架梯就走，不啃。

**代价**：搭梯是纯操作活儿，**数量越大越吃运气**。
> 【你】DE 双冰六炮 要搭 **14 个**，且全在后场 —— "花了两天废寝忘食，太难了"。

**收益**：省掉整个选卡周期里反复补南瓜的操作与阳光（南瓜 125/个，后场十几个）。

## 二、通用三原则【你】

### 1. 前期一定要"满屏种花"
> 前期发育的核心是**涨经济**，能不被啃到的地方全部放花。**布阵时有计划地铲花。**

不要一上来就摆阵 —— 摆阵的植物不产钱，前期会穷死。
**花是"临时脚手架"，阵是"永久建筑"，脚手架先搭，建完再拆。**

### 2. 熬前期靠三样东西
```
① 临时输出：临时的曾哥（放在能收杂的位置）
② 控制：寒冰射手、冰瓜 —— 拖慢尸潮
③ 坚果：硬拖时间
```
> 目的是**把时间买够**，让经济涨起来、让阵摆完、让扶梯有机会出现。

### 3. 搭梯是一个"计划"，不是"等它来"
> 从尸潮里**分离**出扶梯 → **保护**好扶梯 → 用**大蒜引导**它去指定位置 → 保证全程生存。

---

## 三、大蒜：唯一的"定向输送"工具

大蒜让僵尸**换行**。它的价值在于**去向是确定的或近乎确定的**：

| 蒜放在 | 僵尸会去 | 确定性 |
|---|---|---|
| **1 路** | 只能去 **2 路** | ✅ 完全确定 |
| **5 路** | 只能去 **4 路** | ✅ 完全确定 |
| **3 路** | 去 **2 路 或 4 路** | ⚠️ **二选一，会浪费扶梯** |

**这就是"为什么选 1、3、5 路当搭梯通道"**：
- 1、5 路先搭，去向确定，不浪费；
- 3 路最后处理（它的二选一是最后的容错问题）。

### 场地差异【你】
> **后院（PE / FE）比前院简单得多**：因为 1、2 和 5、6 都是陆路，扶梯的去向很清楚，
> 不会出现"5 路陆路 / 3 路二选一"这种浪费。

## 四、三阶段流程

### 阶段 A：纯发育（0~2F）

**选卡**：花、蒜、伞、南瓜、南瓜（复制）、窝瓜、地雷、曾哥套件

```
① 一直种花（能种的地方全种）
② 在 1、3、5 路的 8、9 列放蒜 —— 把僵尸往 2、4 路赶，保护种花区
③ 在 3-7 一类的位置放一个临时曾哥：收掉除铁桶外的所有僵尸
④ 铁桶 → 用地雷或窝瓜处理
⑤ 本阶段结束时：阵里的曾、伞全部就位；南瓜除"搭梯通道的第 4 列"外全部就位；阳光 ≥ 4000
```

> **"通道第 4 列"为什么要留空？**
> 因为那里是**大蒜位 + 扶梯的过道**。占了就没法引导，也没法让扶梯穿过去。

### 阶段 B：布阵 + 开局生存（2~4F）

**选卡**：蒜、双子葵、炮套件、冰瓜套件、火炬、高坚果（按压力选）、双向（有扶梯时可能用到）、其余按僵尸对策

```
① 布底线炮、2/4 路前场炮
② 布 2/4 路冰瓜
③ 布双子葵（发育阶段 1-1、5-1 也放双子葵，后期再换）
④ 在 1、3、5 路的第 4 列放蒜，并持续维护
⑤ 若这局有扶梯：把 1、3、5 路「第 4 列大蒜之前的所有植物」全部清除 ——
   给扶梯让出通道
⑥ 此时场上有 3 炮 + 2 冰瓜 → 已具备前期生存能力，可以开始搭梯
```

### 阶段 C：搭梯（2~4F 起）

**次序铁律：先布完阵，最后才搭梯。越贵的植物越晚搭。**

```
① 前场放大蒜，把扶梯引导到 1、3、5 路
② 2、4 路中任一路搭完 → 把 3-4 的蒜换成「南瓜 + 双向」，准备搭 3 路
③ 2 路（或 4 路）搭完 → 铲掉 1-4（或 5-4）的大蒜，准备搭本行
④ 1 路、5 路的冰瓜是本行最后搭的：等扶梯接近时，快速下「西瓜 → 冰瓜」
```

**为什么冰瓜必须最后搭**【你】：
> **格子如果被炸、或者"刷新"（种植物、铲植物、种紫卡）都会导致扶梯消失。**
> 所以顺序是：先把所有东西摆好 → 最后再做"需要卡时机"的那一步。

【推】换句话说：**搭梯期间，任何对格子的改动都可能把扶梯弄没**。
所以"改动次数最少、改动最晚"的方案就是最优方案。

## 五、风险与放弃条件【你】

| 风险 | 表现 | 对策 |
|---|---|---|
| **小丑** | 搭梯"非常刺激"，技术不行就是**毁阵** | 看实力**放弃搭梯、转向压制**（保住阵比搭完梯重要） |
| **跳跳** | 会偷家 | 带冰，合适时机点冰，让底线曾收掉 |
| **冰车** | 碾通道 | 带地刺；压力大可以考虑布**两路刚地刺** |
| 其它快速僵尸 | 容易从扶梯里分离出来 | 靠大蒜与节奏控制 |
| 慢速僵尸 | 基本不是问题 | — |

> **判断准则**：**搭梯是"锦上添花"，阵是"命"。**
> 一旦搭梯威胁到阵的完整，立刻放弃搭梯 —— 没梯的阵照样能打，塌了的阵不能。

## 六、什么时候该收手【你】

```
前 10F 都见不着一个扶梯  → 可以重开
20F 都还没搭完          → 可以重开
```

【推】为什么是这两个数：14 个梯子意味着需要**十几次**扶梯出现。
若 20F（约 10 个选卡）还搭不完，说明这一局的出怪结构不适合搭梯，
继续投入只会把经济耗空 —— **重开的期望收益更高**。

## 七、检查清单

**阶段 A 结束**
```
□ 阵里的曾、伞全部就位
□ 南瓜除通道第 4 列外全部就位
□ 阳光 ≥ 4000
□ 花已经铺满可种区
```

**阶段 B 结束**
```
□ 底线炮 + 2/4 路前场炮已布
□ 2/4 路冰瓜已布
□ 双子葵已布
□ 1/3/5 路第 4 列大蒜在位并维护
□ 有扶梯 → 通道已清空
```

**搭梯中**
```
□ 每搭完一行，立刻更新"下一行"的蒜位/双向位
□ 冰瓜最后搭
□ 有跳跳 → 先备好冰
□ 有小丑 → 随时准备放弃
```

## 八、这个技术能推广到哪些阵

| 阵 | 梯子数 | 难度 | 备注 |
|---|---|---|---|
| **DE. 双冰六炮** | **14** | 极高（全在后场） | 本文实例 |
| **PE. 电波钟无炮** | **4** | 中（1-2、1-3、2-2、2-3） | 5 路不搭梯（辣椒路）；PE 是后院，通道更清楚 |
| 其它炮阵 / 无炮 | 视阵而定 | — | 原则通用 |

> **共同点**：不管哪个阵，**前期都是"满屏花 + 蒜 + 临时输出"起步，布阵时铲花**。
> 这条之前被我只当成"布阵顺序"，现在要升级成"**发育是一段独立阶段**"。
