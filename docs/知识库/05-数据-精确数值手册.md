## 一、单位体系（先立规矩）

| 项目 | 规定 |
|---|---|
| 空间 | **px**，原点 = `1-1` 格左上角，↓→ 为正 |
| 时间 | **cs**（厘秒，1/100 秒）。`373cs = 3.73s` |
| 判定 | 内存中是 16 位浮点，但**所有判定都向零取整**（抹掉小数） |

**判定规则**：圆判定 `(Δx)² + (Δy)² ≤ R²`，其中 Δx、Δy 已取整 —— 所以判定圆不是数学意义上的圆。

**基准点**：战场可见区左端 `x = −40`，上端 `y = −80`；前院 1-1 豌豆射手 `(40, 80)`；前院 1 路进家普僵 `(−100, 50)`。

**僵尸判定范围计算**（偏移相对僵尸基址，16 进制）：

| 偏移 | 意义 | 普通僵尸 |
|---|---|---|
| `[+8C]` | 防御范围横向偏移 | 36 |
| `[+90]` | 防御范围纵向偏移 | 0 |
| `[+94]` | 防御范围横向宽度 | 42 |
| `[+98]` | 防御范围纵向高度 | 115 |
| `[+9C]` | 攻击范围横向偏移 | 20 |
| `[+A0]` | 攻击范围纵向偏移 | 0 |
| `[+A4]` | 攻击范围横向宽度 | 50 |
| `[+A8]` | 攻击范围纵向高度 | 115 |

```
左行僵尸：左界 = x + 横偏；右界 = 左界 + 横宽
右行僵尸：右界 = x + 120 − 横偏；左界 = 右界 − 横宽
上界 = y + 纵偏；下界 = 上界 + 纵高
例：x=650, y=135 的普僵 → 防御 x:686~728, y:135~250；攻击 x:670~720
```

### 4.1 防具分类（用户 2026-10-23 补充，图鉴核对时给出）

> 原文口径：
> 「报纸破掉时会发愣一两秒，且报纸属于**二类防具**（扶梯、报纸、铁门均为二类防具，
>  在 AoE 伤害、投掷子弹下二类防具不起作用；其余防具属**一类防具**，必须先破坏才能
>  对僵尸造成伤害，但是灰烬、炮、窝瓜可以直接击杀僵尸）」

| 类别 | 有哪些 | 挡什么 | 不挡什么 |
|---|---|---|---|
| **二类防具** | 扶梯（500）· 报纸（150）· 铁门（1100） | **只挡平射**（豌豆 / 双发 / 机枪这类直线子弹） | AoE（溅射）· 投掷子弹（西瓜/冰瓜/玉米/篮球）· 喷雾（大喷菇 / 忧郁菇，图鉴 "can pass through screen doors"）· 灰烬 / 炮 / 窝瓜 |
| **一类防具** | 路障锥 370 · 铁桶 1100 · 橄榄头盔 1400 · 矿工帽 100 … | 所有非灰烬伤害（打光防具才伤本体） | 灰烬 / 玉米炮 / 窝瓜 **直接击杀** |

- 报纸被打掉之后：**发愣 1~2s** → 之后 **1.8s/格** 暴走（图鉴 Newspaper `4.7 / 1.8`）。
- 模型实现：一类折进总血量（对非灰烬伤害等价，灰烬 1800 也一律击杀）；
  二类单独记 `Zombie.shield`，`_hurt(z, dmg, pierce=True)` 才绕过它。

### 4.3 地下状态（矿工）

矿工挖掘时**只有灰烬**（P / A / A′ / N）能造成伤害；
窝瓜、冰瓜、喷雾（大喷菇 / 忧郁菇）、溅射、平射**一律无效**。
模型里用 `_hurt(z, dmg, pierce, src)` 的 `src` 区分来源，
`phase == 'dig'` 时只放行 `src == 'ash'`。

地下状态也**不能被植物选为目标**（`Sim._targetable`）——
否则它挖到 x=20 一蹲，会把单目标伤害和炮的落点全吸走。

**溅射伤害公式**（n = 溅射僵尸数，**不含**被直接命中的那只）：
```
火豌豆：伤害 = 40 / n，取整；上限 13，下限 1
西瓜/冰瓜：伤害 = 574 / n，取整；上限 26，下限 1
```

**同一厘秒的执行顺序**（排错时的关键）：
```
发出子弹或范围伤害 → 植物触发 → 僵尸移动 → 子弹伤害
```
推论：子弹发出的同一厘秒就会移动，存在时间为 1，**击中初始范围**（移动前的范围）。

## 八、玉米加农炮

- **准星**：红叉中心 = 整数 px，`准星x / 80` = 列数。例 `准星x=721` ≡ `9.0125 列`。
- **爆炸中心**（非天台）：`爆炸中心x = 准星x − 7`，`爆炸中心y = 同行植物 y + 40`。
- **梯子南瓜被炸飞条件**（r 行 c 列）：`r−1 ≤ 准星行 ≤ r+1` 且 `80c−113 ≤ 准星x ≤ 80c+126`。
- **闪烁亮度**：由计时除以 75 的余数决定，余数 **0 和 1 最亮**，**38 最暗**。
  → 这就是"等炮闪 5~8 下点冰"这类口诀的来源。

#### 9.1 减速机制（[wiki] 攻略:僵尸速度）

冰车 **免疫控制**（冰/减速都不吃）。其余僵尸被减速时分成两类：

| 类型 | 每 cs 位移 | 每 cs 动画进度 | 包含哪些 |
|---|---|---|---|
| **匀速** | **×0.4** | 不变（没有腿部动画） | 水中潜伏的**潜水**、**跳跳**、**投篮车**、飞行中的**气球**、挖掘中的**矿工**、冲锋中的**海豚**、冰车（免疫，不参与） |
| **非匀速**（两腿驱动） | **×0.5** | **×0.5** | 其余全部 |

推论（实战里最要紧的几条）：
- **冰车**：既不被减速也不被冰冻，只能硬杀。
- **矿工**：只有**地下挖掘**那一段是匀速（×0.4）；出土后被减速就按两腿算（×0.5）。
- **海豚**：骑海豚冲锋（0.8s/格）那一段匀速（×0.4）；跳过之后水豚消失、自己走，按两腿算。
- **跳跳**：全程"以速度实现跳跃"，匀速（×0.4）。
- **动画进度 ×0.5** 的连带影响：**吃东西更慢**（啃食伤害减半）、**巨人举锤周期翻倍**
  （330 → 660cs）、**小丑开盒 / 引信倒计时走一半速**、投篮车投掷间隔不变（它属匀速）。

#### 11.2.3 飞行运动（斜抛）

> 出处：`docs/原始资料/小鬼投掷/小鬼飞行x-t.jpg`、`小鬼飞行y-t.jpg`
> = 贴吧 3499518689 的实测曲线。两图的横轴都是 cs。

- **横向**：`x-t` 是**直线** → **横向速度恒定**，斜率 **≈ 3.07 px/cs**。
- **纵向**：`y-t` 是**标准抛物线** → 纵向是重力匀加速，**只有纵向初速度随机**。
- 对同一起抛的一批小鬼：**初位置相同、横向速度相同、加速度相同**，
  唯一不同的是纵向初速（这决定了落点）。
- 从 `y-t` 反读：**起抛高度 88px**，落地在 **110 / 117 / 124 cs**（三只），
  最高点分别 **127 / 136 / 146 px**（出现在 39 / 44 / 48 cs）。
- 据此反解重力加速度：

  ```
  y(t) = 88 + v0·t − ½·g·t²        v0 = (½·g·T² − 88) / T
  g ≈ 0.0505 px/cs²                T ∈ [110, 125] cs（纵向初速随机区间）
  ```

  自检：`T = 110 / 117 / 124` → 最高点 `127 / 136 / 146`，与实测完全一致。

#### 11.2.4 这组数据对"拦截炮"意味着什么

- 小鬼滞空只有 **110~125cs**（约 1.1~1.25s），比"P 生效 378cs"短得多 —— 所以
  拦截炮必须**先算好再打**，不能等看见小鬼飞了再按。
- 三种拦截时机的物理含义：

  | 时机 | 飞行进度 | 小鬼位置 |
  |---|---|---|
  | 投掷刚刚出手 | 0 ~ 0.2 | 离地约 90~110px，刚从巨人手上飞出 |
  | 飞行到最高点 | 0.35 ~ 0.6 | 离地 127~146px，横向约走了一半 |
  | 将要落地 | 0.75 ~ 0.95 | 离地已很低，落点基本确定 |

- **"高度"走的是 y 轴，不是 z 轴**（用户 2026-10-24 澄清）：这个游戏没有 z 轴，
  小鬼飞行时的高度**就映射在 y 轴上**（可以理解为"行轴"与"高度轴"复用同一个 y；
  y 在变，但**小鬼最终落点不会换行**）。所以爆炸域与小鬼在**同一个二维坐标系**里，
  判定是二维的：爆心在地面附近，往上够 `R = 115`，再加小鬼自身判定体厚度（约 40）
  → 可达高度 **155 > 实测最高点 146**，所以**在最高点也炸得到**。
  这也解释了为什么"投掷出手 / 最高点 / 落地前"三种拦截时机都成立。

- 落点是一个**区间**而不是定值（见 11.2.2），所以"一门炮负责几路"要用
  **覆盖整个落点区间**的落点，不能只瞄 3 列。

### 11.6 啃大蒜的伤害差异
不同僵尸啃食动画速度不同 → 完成进度不同 → 伤害不同。
```
啃大蒜时间 = 1 + ceil(帧数 / 帧速 × 进度 × 100)
啃食伤害   = 正常 ceil(时间/4)×4 ；减速 ceil(时间/8)×4
```
完成进度：多数 0.14 和 0.68｜撑杆 0.38 和 0.8｜读报/梯子 0.42｜雪橇 0.33 和 0.83｜小丑 0.53｜小鬼 0.33 和 0.79

### 12.3 无尽模式：紫卡会涨价（关键）

> **在 Survival: Endless 中，每种紫卡的价格随场上已种植数量递增，被摧毁后相应回落。**
> 幅度：**每多一株 +50 阳光**（同种紫卡分别计算，绿卡不涨）。

```
第 n 株单价    = 基础价 + 50 × (n − 1)
种满 n 株总价  = n × 基础价 + 50 × n(n−1)/2
（若要连基座一起算：再 + n × 基座价）
```

**示例（忧郁菇 15 个）**：
```
基座：15 × 75 = 1125
升级：15 × 150 + 50 × (0+1+…+14) = 2250 + 5250 = 7500
合计：8625 阳光
```

**场上 15 曾时补一个 = 150 + 50×15 = 900 阳光** —— 这是"崩了补不上"的量化根据。
